30번·29번 풀이의 실마리

30번은 0 ≤ x ≤ n, 0 ≤ y ≤ √(x+3)/2인 영역에 들어가는 정사각형 가운데 꼭짓점이 모두 격자점이고 한 변이 √5 이하인 것의 개수 f(n)을 셉니다. 한 변이 √5 이하인 격자 정사각형은 변의 방향에 따라 한 변 1, √2, 2, √5의 네 종류뿐입니다. 경계 곡선 y = √(x+3)/2는 x = 1, 13, 33, 61, …에서 y가 1, 2, 3, 4가 되므로, 높이가 한 칸씩 늘어날 때마다 들어갈 수 있는 정사각형의 종류와 개수가 늘어납니다. 예시 f(14) = 15로 세는 방식을 확인한 뒤 x를 늘려 가며 세면 f(65) = 395, f(66) = 409입니다. 따라서 f(n) ≤ 400인 n의 최댓값은 65입니다. 기울어진 정사각형(한 변 √2, √5)까지 빠짐없이 세는 것이 이 문항의 관건이었습니다.

29번은 [0, 4)에서 −x(x − 4), [4, 8]에서 x − 4인 함수에 대해 길이 4인 구간 [a, a+4]의 적분값을 최소로 만드는 문항입니다. 적분값을 a에 대해 미분하면 f(a + 4) − f(a) = a² − 3a이므로 a = 3에서 극소입니다. 그때 값은 37/6로, 양 끝 a = 0(32/3)이나 a = 4(8)보다 작습니다. 따라서 p + q = 43입니다.
