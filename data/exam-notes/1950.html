30번: f(0) = 0이 두 방정식에 공통으로

f(x) = ax³ + bx² + cx로 두면 f(x) − x = x(ax² + bx + c − 1), f(x) + x = x(ax² + bx + c + 1)입니다. 두 방정식 모두 x = 0을 근으로 가지므로, 서로 다른 실근이 2개가 되려면 각 이차식이 0이 아닌 중근을 갖거나 0과 다른 근 하나를 가져야 합니다. 두 이차식은 상수항만 2 차이라 동시에 0을 근으로 가질 수 없습니다. 첫 번째가 0을 근으로 갖는 경우(c = 1)를 보면, 두 번째 ax² + bx + 2는 중근을 가져 b² = 8a입니다.
