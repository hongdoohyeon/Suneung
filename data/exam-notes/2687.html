가장 많이 틀린 30번(4점, 93.8%)은 로그함수에 대해 조건을 만족시키는 이차함수와 실수를 찾는 문항, 29번(88.8%)은 좌표공간의 세 점과 내적 조건을 만족시키는 점 P를 다룬 벡터 문항이었습니다.

30번·29번 풀이의 실마리

30번은 x − k를 t로 바꿔 G(t) = g(t + k)로 보면 훨씬 단순해집니다. h(k) = |G(0) − f(0)| = G(0)이라는 조건에서 G(0) = f(0)/2 = (ln 2 + 2)/2이고, 이때 G(t) − f(t)는 t = 0에서 음수이면서 최댓값을 가져야 하므로 G′(0) = f′(0) = 5/2입니다. G(t) = f(0)/2 + (5/2)t + at²으로 두면 h(t) = f(t) − G(t)이고, 구간의 오른쪽 끝 t = 1에서의 값이 주어진 최댓값 2e + ln((1+e)/√2)와 같아지려면 a = −7/2입니다. 따라서 g′(k − 1/2) = G′(−1/2) = 5/2 + 7/2 = 6입니다.

29번은 P가 xy평면 위 반지름 4인 원판을 움직이고, Q는 P에서 길이 1만큼 떨어진 점 가운데 PQ와 OA의 내적이 √3/2 이상인 점들입니다. PQ의 x성분이 √3/2 이상이므로 Q의 z좌표는 −1/2부터 1/2 사이입니다. 최솟값은 Q = (0, 0, 1/2)일 때 m = 3/2입니다. 최댓값은 |BQ|² = 21 + 8r − 4z(r은 PQ의 수평 성분 길이)를 r² + z² = 1 위에서 최대로 만드는 문제가 되어, 21 + 4√5 = (1 + 2√5)²에서 M = 1 + 2√5입니다. M + m = 5/2 + 2√5이므로 6(a + b) = 27입니다.
