2020학년도 9월 모평 수학 나형은 수학Ⅱ·미적분Ⅰ·확률과 통계에서 출제되었고, 표준점수 최고점은 142점, 1등급 구분 표준점수는 133점이었습니다. EBSi 가채점 응답자 기준으로 오답률 50%를 넘은 문항이 10개였습니다. 30번(96.6%), 28번(90.2%), 29번(81.8%)이 상위였고, 객관식에서는 19번(73.0%)이 가장 어려웠습니다.

30번: 등차수열을 빼고 남는 것

f(−1), f(0), f(1), f(2)가 등차수열이라는 것은 f에서 어떤 일차식 px + q를 빼면 −1, 0, 1, 2에서 모두 0이 된다는 뜻입니다. 최고차항의 계수가 1이므로 f(x) = (x + 1)x(x − 1)(x − 2) + px + q입니다. 앞의 사차식 h(x)는 x = 1/2에 대해 대칭이고, x = −1과 x = 2에서의 접선 y = −6(x + 1), y = 6(x − 2)는 (1/2, −9)에서 만납니다.

30번: 일차식을 더해도 교점의 x좌표는 그대로

f의 접선은 h의 접선에 같은 일차식 px + q를 더한 것이므로, 두 접선은 여전히 x = 1/2에서 만나고 그 y좌표는 −9 + p/2 + q입니다. 교점이 (k, 0)이므로 k = 1/2, p/2 + q = 9입니다. f(2k) = f(1) = p + q = 20과 연립하면 p = 22, q = −2이고, f(4k) = f(2) = 2p + q = 42입니다.

28번: 역수의 합으로 바꾸기

(나)를 정리하면 c = 2ab/(2a + b), 곧 1/c = 1/b + 1/(2a)입니다. 3^a = 5^b = k^c = t로 두면 1/a = log_t 3, 1/b = log_t 5, 1/c = log_t k이므로 log_t k = log_t 5 + ½log_t 3입니다. k = 5√3이고 k² = 75입니다.

29번과 19번

29번은 가형 28번과 같은 문항으로, 여학생이 받는 연필 수와 남학생이 받는 볼펜 수를 먼저 정하고 나머지를 나누어 49가지입니다. 19번은 급수의 극한을 정적분으로 바꾸어 값을 구하는 문항이며, 정답은 ①입니다.
