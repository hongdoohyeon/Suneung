로그 영역 격자점 30번과 '작은 값' 함수 21번

30번(나형과 공통)은 자연수 n에 대해 로그함수로 정해지는 영역 안에서 x좌표와 y좌표가 같은 정수인 점의 개수를 세는 문항이었습니다. 29번은 삼각형의 한 각을 1 : 2로 나누는 선분 길이의 극한을 구하는 문항, 21번은 곡선 위의 점에서 두 축까지의 거리 중 작은 값으로 만든 함수의 미분가능성을 묻는 문항이었습니다.

29번: 각 C를 1 : 2로 나누면

29번 삼각형 ABC는 AB = 1, ∠A = θ, ∠B = 2θ라 ∠C = π − 3θ입니다. D를 ∠ACD = 2∠BCD가 되게 잡으면 ∠BCD = π/3 − θ이고, 삼각형 BCD에서 ∠BDC = 2π/3 − θ입니다. 사인법칙으로 BC = sinθ/sin3θ, CD = BC × sin2θ/sin(2π/3 − θ)이고, θ가 0에 가까울 때 BC는 1/3, sin2θ는 2θ, sin(2π/3 − θ)는 √3/2에 다가갑니다. 그래서 a = 4/(3√3), 27a² = 16입니다.

21번과 30번

21번 g(t)는 곡선 y = kx²e⁻ˣ 위의 점에서 x축까지 거리 f(t)와 y축까지 거리 |t| 중 작은 값입니다. t < 0 쪽에서는 −kte⁻ᵗ = 1을 만족하는 t가 언제나 하나 있어 두 그래프가 엇갈리며 꺾이는 점이 반드시 생깁니다. 따라서 t > 0 쪽에서는 새 꺾임이 없어야 하고, kte⁻ᵗ의 최댓값 k/e가 1을 넘지 않아야 합니다. k = e이면 y = f(x)가 t = 1에서 직선 y = x에 접해 기울기가 같으므로 g는 미분가능하고, k의 최댓값은 e(⑤)입니다.

30번은 나형과 공통 문항으로, 2ˣ − n ≤ x와 x ≤ log₂(x + n)이 모두 2ˣ ≤ x + n으로 정리된다는 점에서 출발해 n = 1부터 30까지 더한 값은 573입니다.
