A형 30번·28번 풀이의 실마리

A형 30번은 A(−2, 3ⁿ), O(원점)와 자연수 좌표 B(a, b)로 만든 삼각형 가운데 b ≤ log₂ a이고 넓이가 50 이하인 것의 개수 f(n)을 세는 문항입니다. 넓이는 ½(a·3ⁿ + 2b)이므로 조건은 a·3ⁿ + 2b ≤ 100, 그리고 2ᵇ ≤ a입니다. n이 커질수록 a의 범위가 급격히 좁아집니다. n = 1이면 99개, n = 2이면 19개, n = 3이면 2개이므로 f(1) + f(2) + f(3) = 120입니다. b ≤ log₂ a를 '2ᵇ ≤ a'로 바꿔 a 값마다 가능한 b를 세는 것이 출발점이었습니다.

A형 28번은 aₖ = lim (6/k)ⁿ⁺¹ / {(6/k)ⁿ + 1}(n → ∞)에 대해 Σ k·aₖ(k = 1~10)을 구하는 문항입니다. 6/k가 1보다 크면(k < 6) 극한값은 6/k, 1이면(k = 6) 1/2, 1보다 작으면(k > 6) 0입니다. 그래서 k·aₖ는 k = 1~5에서 모두 6, k = 6에서 3, 나머지는 0이라 합은 33입니다. 등비수열의 극한에서 공비가 1인 경우를 따로 떼어 내는 것을 놓치기 쉬운 문항이었습니다.

A형 고난도 문항의 성격

30번은 지수·로그 관계와 삼각형의 넓이 조건을 함께 만족시키는 자연수 순서쌍의 개수를 세는 문항이고, 28번은 공비가 1보다 큰지, 같은지, 작은지에 따라 수열의 극한을 나누어 계산하는 문항입니다. 두 문항 모두 조건에 따른 경우 구분을 빠짐없이 하는 것이 핵심이었습니다.
