30번·29번 풀이의 실마리

30번은 우함수 f가 모든 x에서 ∫ₓ^{x+a} f(t)dt = sin(x + π/3)을 만족할 때, [0, a/2]에서의 식 f(x) = b cos3x + c cos5x의 계수를 찾는 문항입니다. 양변을 미분하면 f(x + a) − f(x) = cos(x + π/3)이고, x 대신 −x − a를 넣어 f가 우함수임을 쓰면 cos(x + a − π/3) = −cos(x + π/3)이 되어 a = 5π/3입니다. x = −a/2를 대입하면 ∫₀^{a/2} f = −1/2이고, 미분한 식에 x = −a/2를 넣으면 f′(a/2) = 1/2입니다. 두 조건에서 b = −9/4, c = 5/2이므로 abc = −(75/8)π, p + q = 83입니다.

29번은 x = 2ln t, y = f(t)로 움직이는 점이 이동한 거리 s와 시각 t 사이에 t = (s + √(s² + 4))/2가 성립하는 상황입니다. 이를 s에 대해 풀면 s = t − 1/t이므로 속력은 1 + 1/t²입니다. x′ = 2/t이므로 f′(t)² = (1 − 1/t²)²이고, t = 2에서 속도가 (1, 3/4)이니 f′(t) = 1 − 1/t²입니다. 따라서 t = 2일 때 가속도의 y성분은 f″(2) = 2/8 = 1/4이고 60a = 15입니다.
