최고점 132점, 나형보다 쉬웠던 가형

2021학년도 9월 모평 수학 가형은 표준점수 최고점이 132점, 1등급 구분 표준점수가 126점이었습니다. EBSi 가채점 응답자 기준으로 오답률 50%를 넘은 문항은 6개로 나형보다 적었습니다. 그래도 30번(92.5%), 28번(87.5%), 29번(81.3%), 21번(75.0%)은 오답률이 70%를 넘었습니다. 출제 범위는 수능과 같은 수학Ⅰ·미적분·확률과 통계였습니다.

30번: 두 곡선 사이에 끼인 직선

직선 y = ax + b가 모든 x에서 −e^(−x+1) 위, e^(x−2) 아래에 있어야 합니다. x → −∞일 때 위쪽 곡선이 0에 가까워지므로 a ≥ 0이고, a = 0이면 b = 0입니다. a > 0이면 b는 위 곡선에 접하는 직선(접점 x = 2 + ln a)과 아래 곡선에 접하는 직선(접점 x = 1 − ln a) 사이에 있어야 합니다. 그래서 a(ln a − 2) ≤ b ≤ −a(1 + ln a)이고, 이 범위가 비지 않으려면 a ≤ √e입니다.

30번: ab의 최댓값과 최솟값

ab의 최댓값은 −a²(1 + ln a)를 미분해 ln a = −3/2일 때 M = e⁻³/2입니다. 최솟값은 a²(ln a − 2)가 a ≤ √e에서 감소하므로 a = √e일 때 m = −3e/2입니다. |M × m³| = (e⁻³/2) × (27e³/8) = 27/16이므로 p + q = 43입니다.

28번: θ → 0에서의 비

반원 위에 ∠POA = θ, ∠QOB = 2θ가 되도록 P, Q를 잡고, 선분 PB와 OQ의 교점 R에서 PQ에 내린 수선의 길이 RH와 두 넓이를 비교합니다. f(θ) + g(θ)는 삼각형 POB와 부채꼴 QOB의 넓이 합에서 삼각형 ROB를 두 번 뺀 값으로 정리됩니다. 길이와 넓이를 θ의 식으로 나타내 극한을 구하면 11/12이고, 답은 23입니다.

29번: 각 상자에 2개 이상

흰 공 4개와 검은 공 6개를 세 상자에 나누되 상자마다 공이 2개 이상이어야 합니다. 흰 공 분배(15가지)와 검은 공 분배(28가지)의 조합 가운데 어느 상자의 공이 2개 미만인 경우를 빼거나, 상자별 흰 공 수로 경우를 나누어 세면 168가지입니다.
