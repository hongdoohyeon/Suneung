나형은 수학Ⅰ·수학Ⅱ·확률과 통계에서 출제되었습니다. 표준점수 최고점은 137점으로 전년(149점)보다 12점 내려가 쉬워졌고, 최고점자는 1,427명, 1등급 구분 표준점수는 131점이었습니다. EBSi 가채점 응답자 기준으로 오답률 50%를 넘은 문항은 6개였고, 30번(4점, 95.4%), 29번(4점, 85.3%), 20번(4점, 78.3%), 18번(61.9%) 순으로 높았습니다.

30번: h(0) = 0이 곧 중근

k(x) = f(x) − g(x)라 하면 k는 최고차항의 계수가 1인 삼차함수입니다. x < 1에서 h = |k|가 미분가능하려면 그 구간 안의 근에서 k의 부호가 바뀌면 안 됩니다. h(0) = 0이므로 x = 0은 k의 중근이고, k(x) = x²(x − a)로 둘 수 있습니다. a > 1이면 0 < x < 1에서 k < 0이라 h = −k입니다.

30번: x = 1에서 이어 붙이기

x = 1에서 h가 연속이려면 −k(1) = k(1) + 2g(1)이므로 g(1) = a − 1입니다. 미분계수가 같으려면 −k′(1) = k′(1) + 2g′(1)이므로 g′(1) = 2a − 3입니다. 이것으로 g(x) = (2a − 3)x + (2 − a)가 정해지고, h(2) = k(2) + 2g(2) = 2a = 5에서 a = 5/2입니다. 따라서 h(4) = k(4) + 2g(4) = 16 × 3/2 + 2 × 15/2 = 39입니다.

29번: 공을 먼저, 주사위는 그다음

3이 적힌 공(확률 2/5)을 꺼내면 주사위 세 번의 합이 10인 경우가 27가지, 4가 적힌 공(확률 3/5)을 꺼내면 네 번의 합이 10인 경우가 80가지입니다. 확률은 2/5 × 27/216 + 3/5 × 80/1296 = 1/20 + 1/27 = 47/540이고, p + q = 587입니다.
