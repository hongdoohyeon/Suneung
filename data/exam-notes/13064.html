남학생이 이웃하는 좌석 29번

30번은 가형과 공통인 로그 영역의 격자점 문항이었습니다. 29번은 좌석표에서 남학생끼리 적어도 한 쌍이 이웃하게 배정될 확률을 구하는 문항, 21번은 삼차함수로 만든 함수가 극값을 하나만 갖도록 하는 조건을 다루는 문항이었습니다.

29번: 여사건은 단 두 가지

29번은 가운데 좌석을 뺀 8개 좌석에 남학생 4명과 여학생 4명을 앉힐 때, 남학생 둘 이상이 앞뒤나 옆으로 이웃할 확률을 묻습니다. 남은 8개 좌석은 가운데를 둘러싼 고리 모양이고, 이 고리에서 서로 이웃하지 않게 4자리를 고르는 방법은 네 모서리 좌석과 네 변 가운데 좌석, 단 두 가지뿐입니다. 남학생 자리를 고르는 전체 경우는 C(8, 4) = 70이므로 p = 1 − 2/70이고, 70p = 68입니다.

30번과 21번: 같은 조건으로 바꾸어 읽기

30번 영역에서 y = x인 정수 점을 셀 때, 2ˣ − n ≤ x와 x ≤ log₂(x + n)은 둘 다 2ˣ ≤ x + n으로 정리되는 같은 조건입니다. 그래서 aₙ은 x > −n이면서 2ˣ − x ≤ n인 정수 x의 개수입니다. x = −(n − 1)부터 0까지는 2ˣ이 1 이하라 모두 성립해 n개가 되고, 양의 정수 쪽에서는 2ˣ − x가 1, 2, 5, 12, 27, …로 커지므로 n에 따라 추가되는 개수가 달라집니다. a₁ = 2, a₂ = 4에서 확인할 수 있고, n = 1부터 30까지 더하면 573입니다.

21번은 F′(x) = f(x) = x³ − 3x + a이므로 F가 극값을 하나만 가지려면 f의 부호가 한 번만 바뀌어야 합니다. f의 극댓값은 a + 2, 극솟값은 a − 2이고, 양수 a에서는 극솟값 a − 2가 0 이상이어야 x = 1 근처에서 부호가 두 번 더 바뀌지 않습니다. a = 2이면 f가 x = 1에서 중근을 가져 부호가 바뀌지 않으므로 최솟값은 2(②)입니다.
