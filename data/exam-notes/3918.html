30번: 경계가 정해 주는 칸 수

30번은 y = 4ˣ, y = a^(−x+4), y = 1로 둘러싸인 영역의 격자점이 20개 이상 40개 이하가 되는 자연수 a의 개수를 묻습니다. 영역은 x = 0부터 4까지 걸쳐 있으므로, 각 정수 x에서 y = 1부터 두 곡선 중 낮은 쪽까지의 점을 세면 됩니다. x = 0과 4에서는 1개, x = 1에서는 4개(a³ ≥ 4)이고, x = 2에서는 a ≥ 4이면 16개, x = 3에서는 a ≤ 64인 한 a개입니다. 그래서 a ≥ 4일 때 개수는 22 + a이고(a = 2, 3이면 12개, 18개), 22 + a ≤ 40에서 a = 4, 5, …, 18의 15개가 답입니다.

28번과 20번

28번은 f(x)f(x − a)가 x = a에서 연속일 조건입니다. f(x − a)는 x = a에서 왼쪽 값 1, 오른쪽 값 7로 끊기므로, 곱이 연속이려면 f(a) × 1 = f(a) × 7, 곧 f(a) = 0이어야 합니다. x + 1 = 0에서 a = −1, −a/2 + 7 = 0에서 a = 14이고(a = 0이면 f(x)²이 1에서 49로 끊김), 합은 13입니다.

20번은 log x의 지표 f와 가수 g에 대해 f − (n + 1)g = n을 푸는 문항입니다. f가 정수이므로 (n + 1)g도 정수여야 해서 g = k/(n + 1)(k = 0, 1, …, n)이고, 그때 f = n + k입니다. log x = n + k + k/(n + 1)을 k에 대해 모두 더하면 log aₙ = n(n + 1) + n(n + 2)/2이므로, n²으로 나눈 극한은 1 + 1/2 = 3/2(②)입니다. 응답의 27.9%는 5/2인 ④를 골랐습니다.
