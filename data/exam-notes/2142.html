최고점 140점, 고난도 12문항

2020학년도 6월 모평 수학 가형은 미적분Ⅱ·확률과 통계·기하와 벡터에서 출제되었습니다. 표준점수 최고점은 140점(만점자 478명), 1등급 구분 표준점수는 130점이었습니다. EBSi 가채점 응답자 기준으로 오답률 50%를 넘은 문항이 12개였고, 30번(92.4%)과 29번(91.2%) 외에 27번(78.7%), 28번(73.5%), 3점 25번(71.0%)도 70%를 넘었습니다.

30번: 먼저 a, b

f(x) = a sin³x + b sin x에 두 조건을 넣으면 a + 2b = 12, 3a + 4b = 40이므로 a = 16, b = −2입니다. sin x = 1일 때 f의 최댓값은 14이고, 1 < t < 14인 직선 y = t는 각 봉우리의 올라가는 쪽과 내려가는 쪽에서 한 번씩 만납니다. 그래서 홀수 번째 x_n은 [π/4, π/3] 구간을 2π씩 옮긴 곳, 짝수 번째는 [2π/3, 3π/4] 구간을 옮긴 곳에 있습니다.

30번: 치환하면 넓이가 된다

c_n의 적분에서 t = f(x_n)으로 치환하면 dt = f′(x_n)dx_n이라 c_n은 f(x)를 x로 적분한 값이 됩니다. 홀수 번째는 ∫_{π/4}^{π/3} f(x)dx = I이고, 짝수 번째는 대칭인 구간을 거꾸로 적분해 −I입니다. 101개를 더하면 51I − 50I = I가 남고, I = [−14cos x + (16/3)cos³x]를 계산하면 −19/3 + (17/3)√2입니다. q − p = 17/3 + 19/3 = 12입니다.

29번과 27·28번

29번은 사분원 위의 점 P와 ∠POQ = π/4를 만족하는 점 Q, 두 선분 위를 움직이는 점 X, Y로 OZ = OP + OX + OY를 만드는 문항입니다. 점 P를 고정했을 때 Z가 그리는 평행사변형을 먼저 그리고 P를 움직여 영역 D 전체를 확정해야 하며, 답은 24입니다. 27번은 공을 다시 넣지 않고 꺼내는 시행의 확률(답 22), 28번은 답이 40인 4점 주관식이었습니다.
