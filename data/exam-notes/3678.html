30번: 반지름 1과 2 사이를 지나는 y = 2ˣ

30번은 1 ≤ a ≤ 10, 1 ≤ b ≤ 100인 자연수 순서쌍 가운데, 곡선 y = 2ˣ이 중심 (a, b)인 반지름 1의 원과는 만나지 않고 반지름 2의 원과는 만나는 것을 세는 문항입니다. 곧 점 (a, b)에서 곡선까지의 거리가 1보다 크고 2 이하인 경우입니다. 곡선이 가팔라 a를 고정하면 조건은 b가 곡선보다 아래에서 2^(a−2) ≤ b < 2^(a−1)이거나, 위에서 2^(a+1) < b ≤ 2^(a+2)인 경우로 정리됩니다. a = 1부터 차례로 세면 4, 9, 18, 36, 44, 16, 32, 37개이고(a = 5부터는 b ≤ 100에 걸려 위쪽이 잘리고, a = 9, 10은 해당 없음), 합은 196입니다.

29·28·21·18번

29번은 P(x ≤ X ≤ 3) = a(3 − x)에 x = 0을 넣으면 전체 확률 1 = 3a라서 a = 1/3입니다. P(0 ≤ X < 1/3) = 1 − (1/3)(3 − 1/3) = 1/9이므로 p + q = 10입니다. 28번은 중심 (3n, 4n), 반지름 3n인 원과 점 (0, −1) 사이 거리의 최대·최소를 비교합니다. 중심까지의 거리 √(25n² + 8n + 1)은 5n에 가까워지므로 aₙ/bₙ은 (5n + 3n)/(5n − 3n)에 다가가 극한값은 4입니다.

21번은 양수 x에서 6x − 6 ≤ f(x) ≤ 2x³ − 2인 삼차함수 f를 찾는 문항입니다. x = 1에서 양쪽 끝이 모두 0이라 f(1) = 0이고, 위아래 경계에 x = 1에서 접해야 하므로 f′(1) = 6입니다. f(x) = x³ + px² + qx − 3에 두 조건을 넣으면 p = q = 1이고, f(3) = 36(①)입니다. 이차 이하라면 이 두 조건을 함께 맞출 수 없습니다.

18번은 중심각 120°의 부채꼴에 내접한 직사각형의 가로가 1, 세로가 1/√3이고, 다음 부채꼴의 반지름이 직사각형의 세로인 1/√3이 되는 구조입니다. 넓이 비가 1/3이므로 S₁ = π/3 − 1/√3에 3/2을 곱해 (π − √3)/2(④)가 극한값입니다.
