30번·29번 풀이의 실마리

30번은 g(x) = |2sin(x + 2|x|) + 1|에 사차함수 f를 합성한 h(x) = f(g(x))가 실수 전체에서 이계도함수를 갖고 그것이 연속이 되는 조건을 찾는 문항입니다. g가 매끄럽지 않은 곳은 두 종류입니다. 하나는 절댓값 안이 0이 되어 g = 0인 점인데, 이 점에서 h′가 이어지려면 f′(0) = 0이어야 합니다. 다른 하나는 |x| 때문에 꺾이는 x = 0입니다. g(0) = 1이고 g의 기울기가 왼쪽 −2, 오른쪽 6으로 다르므로 h′가 이어지려면 f′(1) = 0이고, h″의 좌우 값 4f″(1)과 36f″(1)이 같아야 하므로 f″(1) = 0입니다. 따라서 f′(x) = 4x(x − 1)²이고 f′(3) = 48입니다.

29번은 이면각이 π/4인 두 평면 α, β와 α 위의 A, β 위의 B에서 교선 l에 내린 수선의 발 C, D를 다룹니다. 직선 AB와 β가 이루는 각이 π/6이므로 A에서 β까지의 거리는 AB sin(π/6) = 1이고, 이것이 AC sin(π/4)와 같아 AC = √2입니다. AD = √3이므로 CD = 1입니다. 좌표로 놓고 AB = 2를 맞추면 BD = 1 + √2이고, 사면체 ABCD의 부피는 (1 + √2)/6입니다. 따라서 36(a + b) = 12입니다.
