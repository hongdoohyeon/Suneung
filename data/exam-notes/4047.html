30번: 넓이가 (t³ − s³)/6이 되는 이유

30번은 곡선 y = x² + x 위의 A(s), B(t)와 원점으로 만든 부채꼴 모양 영역의 넓이가 k가 되는 점 (s, t)의 자취 C를 구합니다. 원점을 지나는 두 선분은 넓이 계산에 기여하지 않으므로, 넓이는 곡선을 따라 ½∫(x dy − y dx)를 계산한 값이고 x dy − y dx = x²dx라서 (t³ − s³)/6입니다. C는 t³ − s³ = 6k입니다. C 위에서 (1, 0)까지 거리가 최소인 점에서는 그 점과 (1, 0)을 잇는 방향이 C의 법선 방향 (−3s², 3t²)과 나란해야 하므로 (s − 1)/(−s²) = 1/t입니다. s = 2/3을 넣으면 t = 4/3이고, k = (64/27 − 8/27)/6 = 28/81에서 p + q = 109입니다.

28번: 분모에 숨은 두 근

28번에서 g(x) = a(x + 1)(x − 2)이므로 g(x − 2) = a(x − 1)(x − 4)이고, 두 곡선이 x = −2, 1, 2, 6에서 만나므로 f(x) − g(x − 2) = c(x + 2)(x − 1)(x − 2)(x − 6)(c > 0)입니다. f/g(x − 2) ≤ 1을 {f − g(x − 2)}/g(x − 2) ≤ 0으로 바꾸고 공통 인수 x − 1을 약분하면 (x + 2)(x − 2)(x − 6)/(x − 4) ≤ 0이 되는데, 원래 분모가 0이 되는 x = 1, 4는 빼야 합니다. 해는 −2 ≤ x ≤ 2(x ≠ 1)와 4 < x ≤ 6이고, 정수 −2, −1, 0, 2, 5, 6의 합은 10입니다.
