2021학년도 6월 모평 수학 가형은 표준점수 최고점이 143점, 1등급 구분 표준점수가 132점이었습니다. 기하가 빠진 수학Ⅰ·미적분·확률과 통계 범위로 치른 첫 평가원 모의평가였습니다. EBSi 가채점 응답자 기준으로 오답률 50%를 넘은 문항이 11개였고, 주관식 27~30번이 모두 78%를 넘었습니다. 30번(97.8%), 28번(88.9%), 29번(81.1%)이 상위였고, 객관식에서는 20번(77.5%)이 가장 어려웠습니다.

30번: 꺾이는 점에서만 끊긴다

f는 0 ≤ x < 3에서 |x − 1| + |x − 2|이고 주기가 3입니다. 기울기는 [0, 1)에서 −2, [1, 2)에서 0, [2, 3)에서 2입니다. g(x)는 t = 2^x에서 f의 오른쪽 미분계수에 t ln 2를 곱한 값의 절댓값입니다. 기울기의 크기가 2에서 0, 0에서 2로 바뀌는 t ≡ 1, 2 (mod 3)에서만 g가 불연속이고, t가 3의 배수인 곳은 기울기가 +2에서 −2로 바뀌어도 크기가 같아 연속입니다.

30번: 개수와 합

a ∈ (−5, 5)이면 t = 2^a는 1/32과 32 사이이므로, 해당하는 t는 1부터 31까지의 자연수 가운데 3의 배수가 아닌 21개이고 n = 21입니다. g(a_k)/ln 2는 t ≡ 1인 곳에서 오른쪽 기울기가 0이라 0, t ≡ 2인 곳에서는 2t입니다. 2 + 5 + … + 29 = 155이므로 그 합은 310이고, 답은 21 + 310 = 331입니다.

29번: 고르는 단계와 나누는 단계

검은색 1, 파란색 4, 빨간색 4자루에서 5자루를 고른 뒤 두 학생에게 나눕니다. 색별로 고른 개수를 (k, b, r)로 정하면, 각 색을 두 학생에게 나누는 방법은 (k + 1)(b + 1)(r + 1)가지입니다. k + b + r = 5를 만족하는 모든 경우에 대해 이 값을 더하면 114입니다.

28번과 20번

28번은 두 선분과 원으로 만든 도형의 넓이를 다룬 문항으로 답은 15입니다. 20번은 각의 이등분선과 원으로 둘러싸인 부분이 무한히 반복되는 도형에서 넓이 합의 극한을 구하는 문항입니다. 처음 그림의 두 삼각형이 정삼각형임을 찾는 데서 출발하며, 정답은 ①입니다.
