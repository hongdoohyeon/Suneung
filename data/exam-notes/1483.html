생명과학Ⅰ과 나란히 71점

2022학년도 9월 모평 화학Ⅱ의 표준점수 최고점은 71점으로, 생명과학Ⅰ과 함께 과학탐구에서 가장 높았습니다. 오답률 50%를 넘은 7문항 가운데 20번 평형(3점, 76.1%)이 1위였고, 반응 속도 문항인 17번(2점, 71.1%)과 19번(3점, 66.7%), 기체 실험 18번(2점, 64.2%)이 뒤를 이었습니다.

20번: 1 L가 몇 몰인지부터

(나)에서 A 0.8 g과 C 1 g이 각각 1 L씩, 같은 몰수입니다. 이 몰수를 n으로 두면 질량 보존(2A + B = 2C)에서 분자량 비가 A : B : C = 0.8 : 0.4 : 1로 정해집니다. 부피가 2 L에서 9/4 L로 늘었으니 역반응이 일어난 것이고, B가 n/4 생기면서 A 1.5n, B 0.25n, C 0.5n이 되어 K₁ = 1입니다. (가)도 같은 온도에서 C만으로 평형에 이르므로, B가 z만큼 생긴다고 두고 K = 1을 풀면 z = n/3, 부피 4/3 L, 밀도 x = 3/4 g/L입니다.

20번: 온도를 올린 뒤

5T/4에서는 같은 압력에서 1몰의 부피가 5/4배가 됩니다. (나)의 부피 3 L는 전체 2.4n몰에 해당하므로 B 0.4n, A 1.8n, C 0.2n이고, 이 값으로 K₂ = 5/54가 나옵니다. 따라서 x × K₂/K₁ = 3/4 × 5/54 = 5/72(①)입니다.

17번: 몰 분율 비로 반감기 찾기

2A → 2B + C에서 처음 A를 1몰이라 하고 남은 비율을 f라 하면 전체 몰수는 1.5 − 0.5f, A의 몰 분율은 f/(1.5 − 0.5f)입니다. 20분 때 남은 비율을 p라 하면 40분에는 p²이고, 두 몰 분율의 비는 p(3 − p)/(3 − p²)입니다. 실험 Ⅰ의 11/47에는 p = 1/4, Ⅱ의 5/11에는 p = 1/2이 맞아 반감기는 각각 10분, 20분입니다. 30분 때 Ⅰ의 f = 1/8이므로 x = 2/23입니다. 20분일 때 Ⅱ의 B는 1/2몰, Ⅰ의 C는 3/8몰이고 질량비가 5/6이므로 B : C 화학식량 비는 5 : 8, 질량 보존에서 A : C = 9 : 8입니다. 답은 2/23 × 9/8 = 9/92(①)입니다.

19번과 18번

19번은 A → B + C 반응에서 시간에 따른 부분 압력 변화로 반응 속도를 비교하는 문항입니다. 같은 시간 간격 동안 B의 부분 압력 증가량이 줄어드는 비율에서 반감기를 읽으면 되고, 정답은 ②입니다. 18번은 강철 용기와 실린더에 기체를 나누어 넣고 반응시키는 문항으로, 온도가 일정할 때 기체의 몰수가 압력과 부피의 곱에 비례한다는 관계 하나로 풀립니다. 정답은 ②입니다.
