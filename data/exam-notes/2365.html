30번: 안쪽 함수 g가 값 t를 몇 번 갖는가

g(x) = 2x⁴e^(−x)는 x = 0에서 극솟값 0, x = 4에서 극댓값 G = 512e⁻⁴(약 9.38)를 갖고, x → −∞에서 무한히 커집니다. 그래서 g(x) = t의 해는 t = 0이면 1개, 0 < t < G이면 3개, t = G이면 2개, t > G이면 1개입니다. 최솟값이 0인 사차함수 f에서 h(x) = 0의 해가 4개이려면 f(t) = 0의 근이 t = 0(해 1개)과 0 < t < G인 b(해 3개)여야 하므로 f(t) = ½t²(t − b)²입니다. x = 0에서 h가 극소라는 (나)도 이 식과 맞습니다.

30번: h(x) = 8의 해가 6개

f(t) = 8은 t(t − b) = 4 또는 t(t − b) = −4입니다. 앞의 것은 b보다 큰 양수 근이 하나 있고, 뒤의 것은 b ≥ 4일 때 0과 b 사이에 근이 생깁니다. b < 4이면 해가 3개 이하, b > 4이면 7개 이상이 되고, b = 4일 때만 t = 2(해 3개)와 t = 2 + 2√2(해 3개)로 정확히 6개입니다. f(t) = ½t²(t − 4)²에서 f′(5) = 5 × 1 × 6 = 30입니다.

29번: 내적 조건은 평행한 직선

평면 z = 1 위의 점 P(x, y, 1)에 대해 OA · OP = 3x + y/2 + 2이므로, 세 점의 수선의 발은 6x + y = 10/3, −2, −15/2라는 세 평행선 위에 있습니다. 직선 l은 6x + y = k로 이 선들과 평행하므로, 세 점이 l의 한쪽에만 있으려면 k > 10/3 또는 k < −15/2이어야 합니다. m = 4, M = −8이고 m − M = 12입니다.
