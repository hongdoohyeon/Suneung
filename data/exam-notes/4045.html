A형 최고점 143점, 오답률 50% 초과 7문항

인문계 학생이 주로 본 수학 A형은 종전과 비슷하거나 쉬웠다는 평가가 많았습니다. 표준점수 최고점 143점(3,471명), 1등급 구분 표준점수 137점이었습니다. EBSi 가채점 응답자 기준으로 오답률 50%를 넘은 문항은 7개였습니다.

지표·가수 순서쌍 30번과 행렬 29번

가장 많이 틀린 30번(4점, 91.7%)은 상용로그의 지표와 가수를 좌표로 하는 점에 대해 조건을 만족시키는 순서쌍의 개수를 구하는 문항, 29번(85.1%)은 조건을 만족시키는 이차정사각행렬의 성분을 다루는 문항이었습니다. 21번(58.0%), 28번(57.6%)이 뒤를 이었습니다.

30번: 거리 식이 지표 차를 1로 묶는다

30번은 log k의 지표와 가수를 좌표로 하는 점 Pₖ에 대해 1 ≤ m < n < 100이고 PₘPₙ = √(1 + (log2)²)인 순서쌍을 셉니다. 두 점의 거리 제곱은 (지표 차)² + (가수 차)²이고, 가수 차는 1보다 작으므로 지표 차가 0이면 거리 제곱이 1을 넘을 수 없습니다. 그래서 m은 한 자리, n은 두 자리 수이고, 가수 차의 크기가 log2여야 합니다. log(n/10) − log m = ±log2에서 n = 20m 또는 n = 5m이고, n이 두 자리가 되는 경우는 n = 20m에서 m = 1~4의 4개, n = 5m에서 m = 2~9의 8개입니다. 답은 12입니다.

29번: A² + A + E = O에서 시작

29번은 A³ = E이고 A − E의 역행렬이 있는 이차정사각행렬 A를 다룹니다. A³ − E = (A − E)(A² + A + E) = O에서 A − E를 소거하면 A² + A + E = O입니다. 이를 이용하면 (A − E)² = A² − 2A + E = −3A이므로, (A − E)⁶⁰ = (−3A)³⁰ = 3³⁰A³⁰ = 3³⁰E입니다. 모든 성분의 합은 2 × 3³⁰이라 a = 1, b = 30이고 a + b = 31입니다.
