30번: 합의 조건을 한 칸씩 빼 본다

30번은 5 이하의 자연수 n에 대해 f(1)+…+f(n) = f(n)f(n+1)이 성립하고, n = 3, 4일 때 [n, n+2]에서의 평균변화율이 양수가 아닌 사차함수를 찾는 문항입니다. n과 n−1일 때의 식을 빼면 f(n) = f(n){f(n+1) − f(n−1)}이 되어, 각 n마다 'f(n) = 0이거나 f(n+1) − f(n−1) = 1'이라는 갈림길이 생깁니다. 어느 값도 0이 아니라고 하면 f(5) − f(3) = 1이 되어 (나)에 어긋나므로, 갈림길을 따져 (나)까지 통과하는 경우를 찾으면 f(3) = f(4) = f(5) = 0, f(1) = −1, f(2) = 1입니다. f(x) = (x−3)(x−4)(x−5)(px+q)로 두고 두 값을 넣으면 p = −5/24, q = 1/4이고, f(5/2) = 195/384이므로 128·f(5/2) = 65입니다.

29번: 감소함수와 역함수의 교점

29번의 f(x)는 x < 1에서 일차함수, x ≥ 1에서 cx² + (5/2)x인 함수로, 연속이고 역함수를 가지며 역함수와의 교점의 x좌표가 −1, 1, 2입니다. 교점이 모두 y = x 위에 있다고 보면 f(1) = 1에서 c = −3/2이 나오는데, 이때 f(2) = −1이라 2는 y = x 위의 교점이 아닙니다. f가 감소함수이면 역함수와의 교점은 y = x 위의 점 외에 (p, q)와 (q, p)처럼 짝으로도 생기므로, (1, 1)과 함께 (2, −1), (−1, 2)가 교점입니다. f(−1) = 2와 x = 1에서의 연속 조건 a + b = 1을 함께 풀면 a = −1/2, b = 3/2이고, 2a + 4b − 10c = −1 + 6 + 15 = 20입니다.

28번: 불연속점은 분모의 근

28번에서 x/f(x)가 x = 1, 2에서 불연속이라는 것은 이차함수 f(x)가 x = 1, 2를 근으로 갖는다는 뜻입니다. f(x) = k(x−1)(x−2)로 두면 x → 2일 때 f(x)/(x−2)의 극한은 k와 같고, 이 값이 4이므로 f(4) = 4·3·2 = 24입니다.
