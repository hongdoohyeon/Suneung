30번: 지표가 같으면 a = b뿐

30번은 a ≤ b ≤ 20인 자연수 쌍 가운데 log b − log a ≤ f(a) − f(b)(f는 가수)를 만족하는 것을 셉니다. a와 b의 지표가 같으면 왼쪽은 f(b) − f(a)와 같아지므로, 부등식은 f(b) ≤ f(a), 곧 b ≤ a가 되어 a = b인 20쌍만 남습니다. a가 한 자리, b가 두 자리이면 왼쪽에 지표 차 1이 더해져 1 + 2f(b) ≤ 2f(a)이고, 이는 a ≥ b/√10과 같습니다. b = 10부터 20까지 가능한 a를 세면 6, 6, 6, 5, 5, 5, 4, 4, 4, 3, 3개로 51쌍이고, 합은 71입니다.

21·26·20번

21번은 n = 1, 2에서 f/g의 극한이 0이고 n = 3, 4에서 0이 아닌 값이라는 점에서 출발합니다. g(1) = 0인데 극한이 0이려면 f는 x = 1에서 g보다 높은 차수로 0이 되어야 하므로 (x − 1)²을 인수로 갖고, x = 2에서도 f(2) = 0이라 f(x) = (x − 1)²(x − 2)입니다. f(3) = 4, f(4) = 18을 극한값 2와 6으로 나누면 g(3) = 2, g(4) = 3이고, g(x) = (x − 1)(x² − 7x + 13)에서 g(5) = 12(⑤)입니다.

26번은 Σ(aₖ₊₁ − aₖ)가 처음과 끝만 남아 aₙ₊₁ − a₁ = 2n + 1이 되므로 a₁₀ = 15 + 19 = 34입니다. 20번은 y = log_a(bx − 1)의 x절편 2/b가 y = log_b(ax − 1)의 점근선 x = 1/a 위에 있어야 하므로 b = 2a이고, b > 1에서 1/2 < a < 1인 ③이 정답입니다. 관계식 b = 2a + 1을 고른 ④가 22.8%였습니다.
