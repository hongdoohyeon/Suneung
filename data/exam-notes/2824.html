금속 A~C 산화 환원 20번이 1위

화학Ⅰ은 표준점수 최고점 72점으로 Ⅰ과목 가운데 가장 낮았습니다(1등급 구분 67점).

C4H10 등 탄화수소 구조, 14번

가장 많이 틀린 20번(3점, 76.7%)은 금속 A~C의 산화 환원 반응 실험, 14번(69.5%)은 분자식이 C4H10 등인 탄화수소의 구조를 판단하는 문항이었습니다.

20번·14번 풀이의 실마리

20번은 금속 C를 A^a+ 수용액(비커 Ⅰ)에 넣었다가 꺼내 다시 B^b+ 수용액(비커 Ⅱ)에 넣는 실험으로, 각 단계 뒤 'C(s) : 비커 Ⅰ의 양이온 : 비커 Ⅱ의 양이온'의 몰수 비가 5:1:x → 7:y:2 → 6:3:1로 주어집니다. 비율이라 단계마다 전체 크기가 달라 보이지만, 비커 Ⅰ의 양이온 수는 (나) 이후 변하지 않고 비커 Ⅱ의 양이온 수는 (다) 전까지 변하지 않는다는 점을 기준으로 잡으면 됩니다. 처음 C를 5, A^a+를 1로 두면 (다)의 6:3:1에서 비커 Ⅰ에 생긴 C 이온이 1.5, 비커 Ⅱ에 생긴 C 이온이 0.5입니다. 이를 (나)에 맞추면 x = 1, y = 3입니다. 전하량 보존에서 1.5c = a, 0.5c = b이고 a, b가 3 이하의 정수이므로 c = 2, a = 3, b = 1입니다. 따라서 xy/a = 1, 정답은 ①입니다.

14번은 분자식과 'H 원자 몇 개와 결합한 C 원자' 조건으로 구조를 정하는 문항입니다. (가)는 끝에 CH₃가 두 개인 곧은 사슬 뷰테인, (나)는 =CH−가 하나뿐인 1-뷰텐, (다)는 프로펜입니다. (나)와 분자식이 같으면서 H와 결합하지 않은 C를 가진 분자로 2-메틸프로펜이 있고(ㄱ), (다)와 분자식이 같은 포화 탄화수소로 고리 모양의 사이클로프로페인이 있습니다(ㄴ). C–C–C 결합각은 이중 결합 탄소가 가운데 있는 프로펜이 약 120°로, 사면체 구조인 뷰테인(약 109.5°)보다 큽니다(ㄷ). 정답은 ⑤입니다.
