30번: f(x)/x로 바꾸면 보이는 점화 관계

30번은 감소하는 양수 함수 f에 대해 원점, (t, f(t)), (t+1, f(t+1))로 만든 삼각형의 넓이가 (t+1)/t인 조건을 씁니다. 넓이는 ½{(t+1)f(t) − t·f(t+1)}이고, 양변을 t(t+1)로 나누면 g(x) = f(x)/x에 대해 g(t) − g(t+1) = 2/t²이 됩니다. 구간을 1씩 옮길 때마다 적분값이 ∫2/t²만큼 줄어드는 셈이라, (다)의 ∫₁² g = 2에서 출발하면 ∫₄⁵ g = 1/2입니다. 7/2부터 11/2까지는 [4, 5]를 기준으로 앞뒤 반 구간을 맞바꾸어 계산하면 2 × 1/2 + 2(1/28 − 1/36) = 64/63이 되어 p + q = 127입니다.

29번: 접하는 작은 구 세 개

29번에서 반지름 1인 구가 반지름 3인 구 S와 평면 위에서 접하면 두 중심의 수평 거리는 √(4² − 2²) = 2√3입니다. 그래서 O₁, O₂, O₃은 높이 1에서 반지름 2√3인 원 위에 놓이고, 서로 접하는 이웃끼리는 길이 2인 현으로 이어집니다. 단면 D는 O₃을 지나는 반지름 1의 원판이고, 이를 β에 정사영한 넓이는 π × cos θ입니다. θ는 두 현 O₁O₂와 O₂O₃가 이루는 방향의 차로 현 하나의 중심각과 같고, sin(θ/2) = 1/(2√3)에서 cos θ = 5/6입니다. 넓이는 5π/6이라 p + q = 11입니다.

21·26·20번

21번은 log t의 지표 f(t)가 정수이고 가수 g(t)가 0 이상 1 미만이라는 점이 전부입니다. 9n{g(t) − 1/3}² − n은 −n 이상 3n 미만의 값을 가지므로 가능한 f(t)는 −n부터 3n − 1까지의 정수 4n개이고, 합 2n(2n − 1)을 n²으로 나눈 극한은 4(①)입니다. 26번은 a = 2ˣ, b = 2ʸ, c = 2ᶻ으로 두면 x + y + z = n인 양의 정수해의 개수 C(n−1, 2) = 28이므로 n = 9입니다.

20번 f(x) = xⁿe⁻ˣ에서 f′(x) = xⁿ⁻¹e⁻ˣ(n − x)라 x = n/2를 넣으면 f와 f′이 같고(ㄱ), x = n에서 증가가 감소로 바뀌어 극대입니다(ㄴ). (0, 0)이 변곡점인지는 f″의 인수 xⁿ⁻²의 부호가 0 좌우에서 바뀌느냐에 달려, n이 짝수이면 변곡점이 아니므로 ㄷ은 틀립니다. 답은 ③이고, 응답의 30.7%는 ㄷ까지 고른 ⑤를 택했습니다.
