1등급 컷 66점, 산화 환원과 양적 관계

2020학년도 6월 모평 화학Ⅰ은 1등급 구분 표준점수 66점으로 물리Ⅰ과 함께 과학탐구에서 가장 낮았고, 오답률 50%를 넘은 문항은 6개였습니다. 20번(3점, 76.9%), 19번(3점, 70.9%), 17번(66.7%), 16번(64.6%)이 상위였습니다.

20번: 이온 수가 줄었다가 다시 느는 이유

A^{a+}, B^{b+}, NO₃⁻가 든 수용액에 금속 C를 1 g씩 넣으면 A 이온이 먼저 모두 환원되고 그다음 B 이온이 반응합니다. 전체 이온 수가 34 → 31 → 30 → 31로 줄었다가 다시 느는 것은, A 이온 대신 들어오는 C 이온 수가 적다가 B 이온과 반응할 때부터는 더 많아지기 때문입니다. 전하 보존과 이온 수 변화를 맞추면 a = 1, b = 3, c = 2이고, 처음 A⁺ 이온 9, B³⁺ 이온 4(상댓값)입니다. 4 g을 넣었을 때 x = 31.5이므로 (4/9) × 31.5 = 14(④)입니다.

19번: 남는 반응물 가정하기

실험 Ⅰ에서 B가, 실험 Ⅱ에서 A가 모두 반응한다고 두면 부피 변화에서 (c − 1)/b = 1/2와 c = b가 나와 b = c = 2입니다(ㄱ 오답). 실험 Ⅲ에서는 A가 x/4 g만 반응하고 B x g이 모두 반응하므로 B의 분자량이 A의 2배입니다. 생긴 C의 질량이 5x/4 g이라 C의 분자량은 A의 2.5배입니다(ㄴ). 반응 후 부피 45V/8에서 C의 몰수를 구하면 2.25n이 되어 실험 Ⅱ의 2n과 8 : 9입니다(ㄷ). 정답은 ⑤입니다.

17번과 16번

17번은 HCl 수용액에 NaOH 수용액을 넣으면서 단위 부피당 이온 수 변화를 따지는 문항으로, Cl⁻ 이온의 단위 부피당 수가 절반으로 줄었다면 전체 부피가 2배가 되었다는 점에서 출발합니다. 정답은 ②입니다. 16번 다섯 원소는 Li, Be, Na, Mg, Al입니다. 제1 이온화 에너지가 가장 큰 E가 Be이고, 제2 이온화 에너지가 가장 큰 A가 Li, 두 번째인 B가 Na입니다. 원자 번호가 B가 A보다 크다는 ①이 정답입니다.
