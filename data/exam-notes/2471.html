오답률 상위: 30번 93.0%, 29번 89.8%, 28번 85.0%

가장 많이 틀린 30번(4점, 93.0%)은 함수식이 주어지지 않은 상태에서 접선의 y절편 g(t)에 대한 관계식만으로 정적분 값을 구하는 문항이었습니다. 29번(89.8%)은 두 원 위의 점을 다루는 평면벡터 문항, 28번(85.0%)은 순서쌍 집합에서의 조건부확률 문항, 21번(77.7%)은 삼각함수를 포함한 함수의 객관식 문항이었습니다.

30번: f 대신 g를 적분한다

점 (t, f(t))에서의 접선의 y절편은 g(t) = f(t) − t·f′(t)입니다. 부분적분으로 ∫g = 2∫f − [t·f(t)]가 되므로, 구하는 값 2{f(4)+f(−4)} − ∫₋₄⁴ f(x)dx는 정확히 −½∫₋₄⁴ g(t)dt와 같습니다. 이제 f를 몰라도 g의 적분만 알면 됩니다. 주어진 두 값에서 ∫₀¹ g = 2·(−ln10/4) − (4 + ln17/8)이 나오고, 관계식 g(t+1) − g(t) = 2t/(1+t²)을 [0, 1]에서 적분하면 구간을 1씩 옮길 때마다 ln(1+(k+1)²) − ln(1+k²)씩 더해집니다. [−4, 4]의 여덟 구간을 모두 더하면 로그 항이 서로 지워지고 −32만 남아, 답은 16입니다.

29번과 28번

29번은 A를 원점, B를 (5, 0)에 두면 (가)에서 C = (3, ±4), (나)의 내적 30에서 D의 x좌표가 9로 정해집니다. |CD| < 9를 만족하려면 C와 D가 x축의 같은 쪽에 있어야 하므로, 대칭성에 따라 C = (3, 4)로 두면 D = (9, 3)이고, CD를 지름으로 하는 원은 중심 (6, 7/2), 반지름 √37/2입니다. PA·PB는 AB의 중점 N까지의 거리로 |PN|² − 25/4로 바뀌므로, P가 N에서 가장 먼 점일 때 최대가 되어 55/2 + (7/2)√74, 곧 a + b = 31입니다.

28번은 b가 3의 배수인 원소만 표본공간으로 잡는 조건부확률입니다. n 이하의 3의 배수가 m개일 때, b = 3k마다 가능한 a는 3k개이고 그중 a = b는 1개뿐입니다. 따라서 확률은 m ÷ (3+6+…+3m) = 2/{3(m+1)}이고, 이 값이 1/9이려면 m = 5입니다. n 이하의 3의 배수가 정확히 5개인 n은 15, 16, 17이므로 합은 48입니다.
