30번: 왼쪽 그래프가 덮는 범위

x < 1에서 g(x) = a + (a − 9)/(x − 1)이므로 a < 9이면 왼쪽 그래프는 y = a에서 +∞까지 한 번씩 지나며 올라갑니다(a ≥ 9이면 조건을 만족할 수 없습니다). t ≥ 3일 때 교점이 정확히 2개이고 t가 3보다 조금 작을 때는 2개가 아니어야 하므로, 왼쪽 그래프는 t > 3에서만 나타나야 하고 a = 3입니다.

30번: 오른쪽 삼차함수의 모양

t = 3일 때 왼쪽 교점이 없으니 x ≥ 1에서 f(x) = 3이 두 점에서 성립해야 하고, t > 3에서는 한 점이어야 합니다. f(2) = 3과 함께 생각하면 f는 x = 2에서 극댓값 3을 갖습니다. 또 t = −1에서도 교점이 2개이므로 극솟값이 −1이어야 합니다. f(x) = (x − 2)²(x − c) + 3으로 놓으면 극솟값 −4(c − 2)³/27 + 3 = −1에서 c = 5입니다. 이때 f(1) = −1도 함께 맞아떨어집니다. g(−1) = (−3 − 9)/(−2) = 6이고, (g∘g)(−1) = f(6) = 16 + 3 = 19입니다.

29번: 간격 조건 바꾸기

x₂ − x₁ ≥ 2, x₃ − x₂ ≥ 2, 0 ≤ x₁, x₃ ≤ 10을 만족하는 정수 순서쌍을 셉니다. 간격에서 2씩 빼면 음이 아닌 정수의 합 조건으로 바뀌어 중복조합으로 셀 수 있고, 답은 84입니다.
