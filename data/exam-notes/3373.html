상용로그 지표·가수 A형 30번 91.3%

A형에서 가장 많이 틀린 30번(4점, 91.3%)은 상용로그의 지표와 가수를 이용한 조건 문항이었고, 21번(65.6%)과 29번(정규분포, 63.7%)이 뒤를 이었습니다. B형은 29번(74.8%)과 30번(66.9%)이 가장 어려웠지만 오답률이 70% 안팎에 그쳤습니다.

A형 30번·29번 풀이의 실마리

A형 30번은 log x의 지표 f(x)와 가수 g(x), h(x) = x + 5f(x)에 대해 'f(m) ≤ f(x), g(h(m)) ≤ g(x)'를 만족하는 자연수 m의 개수 p(x)를 x = 2, 4, …, 20에서 더하는 문항입니다. x가 한 자리 수(2~8)이면 m도 한 자리이고 h(m) = m이라, 가수를 비교하는 조건은 m ≤ x와 같아 p(x) = x입니다. x가 두 자리(10~20)가 되면 m은 99 이하이고, 두 자리 m은 h(m) = m + 5로 밀려나 가수를 비교해야 합니다. 그래서 1, 2 같은 한 자리 수와 95~99처럼 h(m)이 100을 넘어 가수가 작아지는 수, 10~15처럼 m + 5가 x보다 작은 수만 조건을 만족합니다. 이렇게 세면 x = 10, 12, 14, 16, 18, 20에서 p(x)는 2, 6, 6, 8, 10, 13이고, 전체 합은 2 + 4 + 6 + 8 + 45 = 65입니다. 지표가 바뀌는 경계와 h(m)이 세 자리로 넘어가는 경계를 함께 따져야 해 오답률이 91.3%였습니다.

A형 29번은 X ~ N(4, 3²)일 때 P(X ≤ 1) + … + P(X ≤ 7)을 구하는 문항입니다. 평균 4를 기준으로 대칭이므로 P(X ≤ n) + P(X ≤ 8 − n) = 1이라, (1, 7), (2, 6), (3, 5)의 세 쌍이 각각 1이 되고 P(X ≤ 4) = 0.5가 더해져 a = 3.5, 10a = 35입니다.

B형은 29번(74.8%)과 30번(66.9%)이 가장 어려웠지만, 만점자가 4%를 넘는 쉬운 시험이었습니다.
