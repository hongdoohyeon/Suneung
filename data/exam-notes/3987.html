30번: 인수분해하면 범위가 보인다

30번 부등식 4ᵏ − (2ⁿ + 4ⁿ)2ᵏ + 8ⁿ ≤ 1의 왼쪽은 8ⁿ = 2ⁿ × 4ⁿ이라 (2ᵏ − 2ⁿ)(2ᵏ − 4ⁿ)으로 인수분해됩니다. 두 정수의 곱이 1 이하인데 곱이 1이 될 수는 없으므로, 곱이 0 이하인 2ⁿ ≤ 2ᵏ ≤ 4ⁿ, 곧 n ≤ k ≤ 2n인 k가 모두 답입니다. aₙ = n + (n + 1) + … + 2n = 3n(n + 1)/2이므로 1/aₙ = (2/3){1/n − 1/(n + 1)}이고, 20까지 더하면 (2/3)(1 − 1/21) = 40/63, p + q = 103입니다.

21번: 감소 구간이 x = −1을 넘으려면

21번 f′(x) = (x + 1)(x² + ax + b)에서 f가 (−∞, 0) 전체에서 감소하려면 x = −1에서 f′의 부호가 바뀌면 안 되므로, x² + ax + b도 x = −1을 근으로 가져 b = a − 1이어야 합니다. 그러면 f′(x) = (x + 1)²(x + a − 1)이고, 감소·증가 조건에서 −1 ≤ a ≤ 1입니다. 이 범위에서 a² + (a − 1)²의 최솟값은 a = 1/2일 때 1/2, 최댓값은 a = −1일 때 5라 M + m = 11/2(③)입니다. 응답의 24.4%가 ④를 골랐습니다.
