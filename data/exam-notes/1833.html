30번: 극대점 x = −1과 근의 합

f는 x = −1에서 극대인 이차함수이므로 f(x) = a(x + 1)² + c(a < 0)이고, g(x) = px³ + qx + r입니다. x = 0에서 미분가능하려면 q = f′(0) = 2a, r = f(0) = a + c입니다. h(x) = h(0)의 근은 x ≤ 0에서 0과 −2이고, x > 0에서는 px² + q = 0의 양수 근입니다. 모든 근의 합이 1이므로 그 양수 근은 3이고, q = −9p입니다.

30번: 최댓값과 최솟값의 차

[−2, 3]에서 최댓값은 f의 꼭짓점 값 c = r − a, 최솟값은 g가 극소가 되는 x = √3에서의 r − 6√3p입니다. 그 차 −a + 6√3p = (9/2 + 6√3)p가 3 + 4√3이므로 p = 2/3, q = −6, a = −3입니다. h′(−3) = f′(−3) = 12, h′(4) = g′(4) = 32 − 6 = 26이라 답은 38입니다.

29번과 25번

29번은 A = {1, 2, 3, 4}에서 A로의 함수 256개 가운데 f(1) × f(2) ≥ 9이고 치역의 원소가 3개인 함수를 셉니다. (f(1), f(2))가 (3, 3), (3, 4), (4, 3), (4, 4)인 경우로 나누어 f(3), f(4)를 정하면 32개입니다. 확률은 32/256이고 120p = 15입니다. 25번은 S₆/S₃ = 1 + r³이므로 1 + r³ = 2r³ − 7에서 r³ = 8이고, a₇ = r⁶ = 64입니다.
