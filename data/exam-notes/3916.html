29번: 정사영 두 번을 빼면 남는 것

29번은 반지름 2인 구 위의 두 점 P, Q에 대해 2|PQ|² − |P₁Q₁|² − |P₂Q₂|²의 최댓값을 묻습니다. 벡터 v = PQ를 평면에 정사영하면 법선 방향 성분만 사라지므로 |P₁Q₁|² = |v|² − (v·e)², |P₂Q₂|² = |v|² − (v·n)²입니다(e = (0, 1, 0), n = (0, 1, √3)/2). 그러면 식은 (v·e)² + (v·n)²만 남습니다. 두 단위 법선이 이루는 각은 60°라 이 값은 v가 두 법선의 이등분 방향일 때 가장 크고, |v|²(1 + cos60°)가 됩니다. |v|는 지름 4까지 가능하므로 최댓값은 16 × 3/2 = 24입니다.

30번: 변곡점 두 개로 f를 정하기

30번 g(x) = f(x)e⁻ˣ에서 g″ = (f − 2f′ + f″)e⁻ˣ이므로, 변곡점이 x = 1, 4이려면 f − 2f′ + f″ = p(x − 1)(x − 4)입니다. 계수를 맞추면 f(x) = p(x² − x)입니다. 점 (0, k)에서 그은 접선은 접점 t에서 k = g(t) − t·g′(t) = p·t²(t − 2)e⁻ᵗ을 만족하고, 이 함수는 t = 0에서 극대 0, t = 1에서 극소 −p/e, t = 4에서 극대 32p/e⁴를 가집니다. 접선이 3개인 k의 범위가 −p/e < k < 0이므로 p = e이고, g(−2) × g(4) = 6e³ × 12e⁻³ = 72입니다.

21번과 28번

21번은 f(x) = (π/2)∫₁^(x+1) f(t)dt를 미분하면 f′(x) = (π/2)f(x + 1)이 되어, 구하는 적분 속 f(x + 1)을 (2/π)f′(x)로 바꿀 수 있다는 점이 핵심입니다. 부분적분 뒤 남는 ∫₀¹ f는 x = −1을 넣은 식과 f(−1) = −f(1) = −1에서 2/π로 정해지므로, 값은 π²(2/π − 4/π²) = 2(π − 2)(①)입니다. 정답률은 30.0%였습니다.

28번은 AC = AD = AP = 2/sin(θ/2)를 L이라 하면 삼각형 BDP의 넓이가 삼각형 APD에서 APB를 뺀 ½L(L − 4)sin2θ입니다. θ가 0에 가까울 때 L ≈ 4/θ이므로 θ × S(θ)는 16에 다가갑니다.
