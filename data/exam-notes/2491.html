20번: 양이온 수의 감소로 전하를 맞춘다

20번은 Aᵃ⁺과 Bᵇ⁺이 든 수용액에 금속 C를 3몰씩 두 번 넣는 실험입니다. 전체 양이온 수는 13 → 10 → 9몰로 줄었고, (나)에서는 A만 석출되었으며 (다)에서는 A와 B가 1:1로 석출되었습니다. (나) 뒤에는 C^c+가 3몰 있으므로 A와 B는 합쳐서 7몰이고, (다) 뒤에는 B 3몰과 C^c+ 6몰만 남습니다. 따라서 (다)에서는 A와 B가 2몰씩 줄었고, (나) 뒤의 A는 2몰, B는 5몰입니다. (가)에는 A가 8몰 있었으므로 (나)에서 C 3몰이 A 6몰을 석출했고, 이로써 c = 2a, 곧 a = 1, c = 2입니다. (다)에서 C 3몰이 내놓은 전자 6몰 가운데 2몰이 A 2몰에, 4몰이 B 2몰에 쓰였으므로 b = 2이고, 구하는 값은 (5/2) × 2 = 5, 정답은 ②입니다.

19번: 고리 모양과 평면 구조를 가르는 조건

19번은 C₆H_a, C_xH₄, C_yH_b인 탄화수소 (가)~(다)에서 'C 원자 3개와 결합한 C 원자 수'가 각각 0, 0, 1이고, x + y = 6, a − b = 4, 평면 구조는 1가지라는 조건을 주었습니다. 각 C 원자에 결합한 H 수가 같은 (가)는 C₆H₆이나 C₆H₁₂일 수 있는데, C₆H₆으로 보면 (나)와 (다)도 모두 평면 구조가 되어 조건에 어긋나므로 (가)는 사이클로헥세인 C₆H₁₂입니다. 그러면 b = 8이고, 사슬 모양이면서 가지가 하나 있는 (다)는 C₄H₈, (나)는 C₂H₄입니다. 사이클로헥세인의 C–C–C 결합각은 120°가 아니라 약 109.5°이고, 에텐은 평면 구조이며, 탄소 3개와 결합한 탄소가 이중 결합에 놓인 (다)는 모든 C가 한 평면에 있습니다. 정답은 ⑤입니다.

16번 기체의 분자량 비, 18번 혼합 용액의 이온 수

16번은 같은 온도·압력에서 두 기체 (가), (나)의 단위 질량당 부피가 3:4로 주어진 문항입니다. 단위 부피당 질량은 그 역수이고 분자량에 비례하므로, 분자량 비는 (가):(나) = 4:3이며 질량이 같을 때 분자 수 비는 3:4입니다. 이 비율과 실험식을 결합해 분자식을 정하는 문항이었고, 정답은 ①입니다. 18번은 HCl, HBr, NaOH 수용액을 섞은 세 실험에서 (나)와 (다)의 총 부피와 OH⁻ 수가 같다는 점으로 단위 부피당 이온 수를 맞추는 문항이었습니다. 혼합 전 A와 B의 단위 부피당 H⁺ 수가 4.0과 1.0으로 정해지는 것이 출발점이었고, 정답은 ④입니다.
