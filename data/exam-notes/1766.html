30번: 극값이 하나뿐이라는 조건

f(1) = f(3) = 0이므로 f(x) = c(x − 1)(x − 3)(x − b)로 둡니다. 1과 3 사이에는 언제나 f′ = 0인 점이 하나 있습니다. 그러니 x ≥ 1에서 그런 점이 하나뿐이려면 나머지 근 b가 1보다 작아야 합니다. b가 3보다 크거나 1과 3 사이, 또는 1이나 3과 겹치면 x ≥ 1에서 f′ = 0인 점이 둘이 됩니다.

30번: |f(x)f(a − x)|가 매끄러우려면

h(x) = f(x)f(a − x)의 근은 b, 1, 3과 a − 3, a − 1, a − b입니다. |h|가 모든 점에서 미분가능하려면 부호가 바뀌는 단순근이 없어야 하므로, 두 묶음의 근이 크기 순서대로 짝을 이뤄 모두 중근이 되어야 합니다. b = a − 3, 1 = a − 1, 3 = a − b에서 a = 2, b = −1입니다. f(x) = c(x + 1)(x − 1)(x − 3)이면 f(0) = 3c, f(8) = 315c, f(−6) = −315c입니다. 따라서 g(8)/(f(0) × f(8)) = 315²c²/(3c × 315c) = 105입니다.
