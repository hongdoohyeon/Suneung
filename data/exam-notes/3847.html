30번: 지표와 가수를 나누어 읽는 세 조건

가장 많이 틀린 30번은 log x의 지표를 f(x), 가수를 g(x)라 할 때 두 양수 a, b에 대한 세 조건으로 ab를 구하는 문항입니다. (가) f(a) + g(b) = 9/4에서 지표는 정수, 가수는 0 이상 1 미만이므로 f(a) = 2, g(b) = 1/4로 바로 갈라집니다. 정수 부분과 소수 부분을 나누어 보는 이 첫 단계가 문항 전체의 열쇠입니다.

(나) g(a) = g(1/a) + g(b)에서는 가수가 0이 아니면 log(1/a)의 가수가 1 − g(a)가 된다는 성질을 써서 g(a) = 5/8을 얻습니다. (다) f(b) = f(1/b) + f(a⁵)도 같은 원리로 f(1/b) = −f(b) − 1이 되고, log a = 21/8이니 log a⁵ = 105/8의 지표 13을 넣으면 f(b) = 6입니다. 따라서 log ab = 21/8 + 25/4 = 71/8이고 m + n = 79입니다. 역수를 취했을 때 지표와 가수가 어떻게 바뀌는지를 정확히 알아야 세 조건이 이어집니다.

29번: 톱니 모양 그래프와 로그 곡선

29번의 f(x)는 −1 ≤ x < 1에서 |2x|이고 주기가 2인 함수라, 0과 2 사이를 오르내리는 톱니 모양입니다. 곡선 y = log₂ₙ x는 x = 1에서 0이고 x = 4n²에서 2에 닿으므로, 1 ≤ x ≤ 4n² 구간에서만 톱니와 만날 수 있습니다. [1, 2]에서 한 번, 그 뒤 길이 2인 톱니 하나마다 두 번씩 만나므로 aₙ = 1 + 2(2n² − 1) = 4n² − 1입니다. n = 1부터 7까지 더하면 553입니다. 마지막 톱니 끝 x = 4n²에서는 f가 0이라 로그 곡선과 만나지 않는다는 경계 확인이 필요합니다.
