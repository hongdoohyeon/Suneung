평형 20번과 반응 속도 18번이 같은 71.2%

화학Ⅱ는 표준점수 최고점 72점, 1등급 구분 68점이었습니다.

기체 A의 분해 평형

가장 많이 틀린 20번(3점, 71.2%)은 기체 A의 분해 반응 평형 상수 문항, 18번(71.2%)은 반응 속도식 문항이었습니다.

20번·18번 풀이의 실마리

20번은 대기압이 일정한 실린더에서 2A(g) ⇄ bB(g) + C(g) 반응이 일어나는 문항입니다. A 2몰이 T K에서 평형 Ⅰ에 이르자 부피가 5V/4가 되었으므로 전체 몰수는 2.5몰이고, B와 A의 부분 압력이 같다는 조건까지 맞추면 b = 2입니다. 평형 Ⅰ의 몰수는 A 1, B 1, C 0.5몰입니다. 5T/4 K의 평형 Ⅱ에서는 P_B/P_A = 2라 A 2/3, B 4/3, C 2/3몰이 되고, 부피는 몰수와 절대 온도에 함께 비례해 5V/3입니다. 농도로 K를 계산하면 K_Ⅰ = 0.4/V, K_Ⅱ = 1.6/V이므로 비는 1/4, 정답은 ①입니다. 압력이 일정하므로 부피가 몰수뿐 아니라 온도에 따라서도 변한다는 점을 놓치면 틀리기 쉬운 문항이었습니다.

18번은 2A(g) → 2B(g) + C(g)를 두 온도에서 진행시키며 생성물 밀도를 잰 표입니다. T₁에서 B의 밀도는 10분마다 9.6, 4.8, 2.4씩 늘어 증가량이 반씩 줄어드므로 1차 반응이고 반감기는 10분입니다. 속도 상수가 2배인 T₂에서는 반감기가 5분이라, C 밀도 4.8은 최종값의 3/4에 해당해 최종 C 밀도가 6.4입니다. 최종 B 밀도 19.2와 C 밀도 6.4를 분자량 비(B가 C의 5/8)와 계수 비로 되돌리면 처음 A의 농도는 T₁이 T₂의 2.4배입니다. 초기 속도 비는 (1/2) × 2.4 = 6/5, 정답은 ④입니다.
