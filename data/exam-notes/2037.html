최고점 135점, 29·30번이 93% 이상

2020학년도 9월 모평 수학 가형은 미적분Ⅱ·확률과 통계·기하와 벡터에서 출제되었고, 표준점수 최고점은 135점, 1등급 구분 표준점수는 128점이었습니다. EBSi 가채점 응답자 기준으로 오답률 50%를 넘은 문항은 7개였습니다. 30번(96.1%)과 29번(93.7%)이 크게 앞섰고 21번(72.1%), 28번(61.9%)이 뒤를 이었습니다.

30번: 대입할 x를 고르는 감각

f′(x² + x + 1) = πf(1)sin πx + f(3)x + 5x²에 x = 0을 넣으면 f′(1) = 0, x = −1을 넣으면 f′(1) = −f(3) + 5라 f(3) = 5입니다. 양변에 (2x + 1)을 곱하면 왼쪽은 f(x² + x + 1)의 도함수가 됩니다. 이를 0부터 1까지 적분하면 f(3) − f(1) = 4f(1) + 10이어서 f(1) = −1입니다. 0부터 2까지 적분하면 사인 항이 4, 다항식 항이 90이 되어 f(7) = −1 + 4 + 90 = 93입니다.

29번: 내적 조건이 x좌표를 고정한다

점 P(x, y, z)가 평면 x + y + √2z = 0 위에 있고 OA·AP = 4(x − 4) = 6이므로 x = 11/2로 정해집니다. 그러면 AP·OP = |OP|² − OA·OP = |OP|² − 22입니다. 평면 위에서 x = 11/2인 점까지의 거리는 최소 약 6.35이므로 |OP|로 가능한 9 이하의 자연수는 7, 8, 9입니다. M = 81 − 22 = 59, m = 49 − 22 = 27이고 M + m = 86입니다.

28번과 21번

28번은 여학생 3명이 같은 수의 연필(1자루 이상)을, 남학생 2명이 같은 수의 볼펜(1자루 이상)을 받는 문항입니다. 여학생 몫을 1자루 또는 2자루로 정하고, 남은 연필은 남학생에게, 남은 볼펜은 여학생에게 나누면 모두 49가지입니다. 21번은 두 점을 초점으로 하는 타원과 그 접선으로 직사각형 넓이의 최댓값을 구하는 문항이며, 정답은 ⑤입니다.
