2019학년도 수능 수학 가형 해설

최고점 133점, 29·30번이 92% 이상

2019학년도 수능 수학 가형은 미적분Ⅱ·확률과 통계·기하와 벡터에서 출제되었습니다. 표준점수 최고점은 133점(655명), 1등급 구분 표준점수는 126점이었습니다. EBSi 가채점 응답자 기준으로 오답률 50%를 넘은 문항은 7개였고, 30번(94.4%)과 29번(92.6%)이 크게 앞섰습니다. 21번(63.0%)과 19번(57.5%)이 뒤를 이었습니다.

30번: g의 극값이 생기는 두 경우

g(x) = 1/(2 + sin f(x))는 cos f(x) = 0인 곳(sin f = ±1)과 f′(x) = 0인 곳에서 극값을 가질 수 있습니다. g(0) = 2/5에서 sin f(0) = 1/2이고 0 < f(0) < π/2이므로 f(0) = π/6입니다. 이때 cos f(0) ≠ 0이니 x = 0이 극값이려면 f′(0) = 0이어야 하고, f(x) = 6πx³ + bx² + π/6로 쓸 수 있습니다.

30번: α₅가 f의 극솟점

(나)는 sin f(α₅) = sin f(α₂) + 1/2입니다. f가 0에서 극대를 지나 내려가면 f = −π/2, −3π/2, −5π/2를 지날 때마다 sin이 −1, 1, −1인 극값이 생깁니다. 그러니 α₂에서 sin 값은 −1이고, sin f(α₅) = −1/2이 되려면 α₅는 f의 극솟점이며 극솟값이 −17π/6이어야 합니다. 극솟점을 x₀라 하면 f(x₀) − f(0) = −3πx₀³ = −3π에서 x₀ = 1, b = −9π입니다. f(−1/2) = π/6 − 3π, f′(−1/2) = 27π/2를 넣으면 g′(−1/2) = 3√3π이고, a² = 27입니다.

29번: 벡터 합이 그리는 영역

AX = (1/4)(AP + AR) + (1/2)AQ에서 P, R이 각각 AB, AC 위를 움직이면 (1/4)(AP + AR)은 AB, AC의 1/4을 두 변으로 하는 평행사변형을 덮습니다. 여기에 Q가 BC 위를 움직이며 더해지는 (1/2)AQ가 그 평행사변형을 BC 방향으로 밀어 넓힙니다. 꼭짓점들을 모아 볼록 다각형의 넓이를 구하면 삼각형 넓이 9의 5/8인 45/8이고, p + q = 53입니다.

21번과 19번

21번은 미분가능성 조건으로 함수를 정하는 객관식으로 정답은 ④, 19번은 정삼각형을 밑면으로 하는 사면체에서 삼수선의 정리로 선분의 길이를 구하는 문항이며 정답은 ③입니다.
