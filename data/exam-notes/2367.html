(f∘f)(x) = x의 근은 f(x) = x인 고정점과, f(p) = q, f(q) = p처럼 서로 자리를 바꾸는 두 점으로 이루어집니다. 삼차함수의 고정점은 많아야 3개인데 근이 다섯 개이고 f′(1), f′(2)가 모두 음수이므로, 1과 2가 서로 바뀌는 쌍이고 0, a, b가 고정점입니다. f(x) = x + kx(x − a)(x − b)로 놓으면 f(1) = 2, f(2) = 1에서 k(1 − a)(1 − b) = 1, 2k(2 − a)(2 − b) = −1입니다.

29번: 이동 거리의 합은 n²/25

Aₙ까지 이동한 거리는 (1 + 3 + … + (2n − 1))/25 = n²/25입니다. 계단 모양 경로에서 직선 y = x 위의 점은 이동 거리가 짝수인 곳, 곧 (k, k)이고 그때 이동 거리는 2k입니다. n²/25가 짝수가 되려면 n²이 50의 배수여야 하므로 n = 10, 20, …이고, 이동 거리는 4, 16, …입니다. 두 번째 점은 (8, 8)이라 a = 8입니다.
