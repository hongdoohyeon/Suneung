30번·29번 풀이의 실마리

30번은 log₂(na − a²)와 log₂(nb − b²)가 같은 자연수 k이고 0 < b − a ≤ n/2인 a, b가 존재하는 n을 찾는 문항입니다. 두 로그값이 같다는 것은 a, b가 이차방정식 x² − nx + 2ᵏ = 0의 서로 다른 두 근이라는 뜻이고, 두 근의 차는 √(n² − 4·2ᵏ)입니다. 이 값이 0보다 크고 n/2 이하이려면 3n²/16 ≤ 2ᵏ < n²/4를 만족하는 자연수 k가 있어야 합니다. 20 이하에서 이를 만족하는 n은 3, 6, 9, 12, 13, 17, 18이고, 합은 78입니다. 로그 조건을 이차방정식의 근의 조건으로 바꾸는 것이 출발점이었습니다.

29번은 꺾은선 y = f(x) 위의 점에서 A(−1, −1)과 B(1, 2)까지 거리의 제곱 가운데 크지 않은 값을 g(x)라 할 때, g가 미분가능하지 않은 점을 찾는 문항입니다. f가 꺾이는 x = 1에서는 B까지 거리의 제곱이 양쪽 모두 미분계수 0으로 매끄럽게 이어지므로 문제가 되지 않습니다. 결국 미분가능하지 않은 점은 두 거리의 제곱이 같아지면서 '작은 쪽'이 바뀌는 곳뿐입니다. 이를 각 구간에서 풀면 x = −3/10과 x = 21/8이고, p = 93/40이라 80p = 186입니다.
