개인정보처리방침

시행일자 · 2026년 10월 26일

1. 개요

기출해체분석기(이하 "서비스")는 회원가입·로그인 없이 누구나 자유롭게 이용할 수 있는 정적 웹사이트입니다. 서비스는 이름·연락처·계정 정보를 직접 수집하지 않습니다. 다만 문항 검색의 품질을 개선하기 위해 검색어·검색 조건과 검색 화면에서의 선택 기록을 저장하며, 그 내용과 이용 목적은 아래 3번에서 안내합니다. 일부 외부 서비스(웹 호스팅·CDN·광고)가 통상적인 웹 운영 과정에서 자동 수집하는 정보가 있을 수 있습니다. 본 방침은 그 범위를 안내합니다.

2. 자동으로 수집되는 정보

이용자가 서비스에 접속하면 다음 정보가 자동으로 수집·기록될 수 있습니다.

  • IP 주소, 브라우저 종류·버전, 운영체제, 접속 일시, 접속 경로(Referer), 요청 URL
  • 쿠키 및 유사 기술(로컬 스토리지)에 저장된 식별자

위 정보는 서비스 안정 운영, 이상 트래픽 차단, 익명 통계 분석 목적으로만 사용됩니다.

3. 검색 데이터 수집·이용

문항 검색 기능을 개선하기 위해 다음 정보를 수집·저장합니다.

  • 검색어와 검색 조건(과목·학년도·시험·문항 번호·단원 등 필터)
  • 검색 결과 수, 결과로 표시된 문항·지문의 식별자, 결과 정렬 방식
  • 이용자가 누른 결과·필터·추천 검색어 등 검색 화면에서의 선택 기록
  • 검색 요청을 구분하기 위한 무작위 세션 식별자(브라우저 세션마다 새로 생성)

위 정보는 ① 검색 결과의 관련도·정렬 개선, ② 오타·동의어·시험 정보 검색 규칙 개선, ③ 검색 실패·불편 지점 분석, ④ 검색 품질 통계 작성에 사용합니다. 광고 맞춤화나 이용자 프로파일링에는 사용하지 않으며, 제3자에게 판매·제공하지 않습니다.

검색 로그에는 이름·이메일·전화번호·계정 정보·IP 주소를 저장하지 않습니다. 검색어에 개인정보를 입력하지 말아 주세요. 호스팅·CDN 사업자의 접속 로그는 2번·5번 항목을 따릅니다.

검색 로그는 수집일로부터 180일간 보관한 뒤 파기합니다. 다만 개인을 식별할 수 없는 형태로 만든 검색 품질 통계는 그보다 오래 보관할 수 있습니다.

4. 쿠키 사용

서비스는 이용자 편의를 위해 다음 용도로 쿠키 또는 로컬 스토리지를 사용할 수 있습니다.

  • 필터·검색 설정 임시 저장 (브라우저에만 저장, 서버 전송 없음)
  • 최근 본 자료 목록 저장 — 최대 8건 (브라우저에만 저장, 서버 전송 없음)
  • 방문·이용 통계 분석을 위한 쿠키(Google Analytics, _ga·_ga_* 등) — 익명 집계 목적
  • 광고 영역(아래 5번 항목)에서 제3자가 설정하는 쿠키

이용자는 브라우저 설정에서 쿠키 저장을 거부하거나 삭제할 수 있습니다. 쿠키 거부 시 일부 기능이 제한될 수 있습니다.

5. 제3자 서비스 (광고·CDN·호스팅)

서비스는 운영을 위해 다음 외부 서비스를 이용합니다. 각 사업자의 자체 정책에 따라 일부 정보가 처리될 수 있습니다.

  • GitHub Pages — 정적 파일 호스팅. 접속 로그 자동 수집. 정책
  • Cloudflare — CDN·DDoS 방어 및 익명 방문자 통계(Web Analytics, 쿠키 미사용). 접속 로그·보안 이벤트 자동 수집. 정책
  • Google Analytics (GA4) — 익명 방문·이용 통계 분석. 쿠키(_ga·_ga_*) 사용. 정책
  • Google AdSense — 광고 송출 (활성화 시). 쿠키 기반 맞춤 광고. 정책
  • Kakao AdFit — 광고 송출 (활성화 시). 정책
  • TypeSafe AI (JEV) — 기출검색에 입력한 문장형 검색어와 자료 오류 제보 내용을 자동 분류(필터 해석·제보 유형 판별)하는 데 쓰입니다. 검색어·제보 문장만 전달되며 IP 등 식별 정보는 전달하지 않습니다. 사이트

광고 맞춤화를 원하지 않을 경우 Google 광고 설정 또는 브라우저 추적 차단 설정을 통해 거부할 수 있습니다.

6. 개인정보 보유 기간

서비스는 이름·연락처·계정 정보를 저장하지 않습니다. 검색 로그는 위 3번에 적힌 기간(180일) 동안 보관한 뒤 파기합니다. 제3자 서비스에서 수집한 정보의 보유 기간은 해당 사업자 정책을 따릅니다.

자료 오류 제보: 이용자가 직접 입력한 제보 내용(오류 종류·자료 종류·설명)과 제보한 페이지 주소만 저장하며, 이름·연락처·IP 주소는 저장하지 않습니다. 제보는 자료 확인·수정에만 쓰이고 90일 뒤 자동 삭제됩니다. 설명란에 개인정보를 적지 말아 주세요.
