## 수정한 규칙

1. 원본 PDF SHA, 페이지, 문항 좌표, 전체 문항 크롭이 모든 구조 후보의 기준이다. 시각 객체가 있는 문항은 평탄화한 문단을 `normalized`로 승격하지 않는다.
2. 비트맵 객체만 찾지 않는다. PDF의 길이가 0인 가로·세로 선분도 검사하여 교차 격자를 `vector_grid_candidate`로 만들고, 셀별 좌표·원시 글자를 저장한다. 행·열 수와 셀 원문은 후보일 뿐이다.
3. 표·그래프·삽화·흐름도·지도·사진은 별도 유형이다. 표의 셀 숫자를 찾았다고 그림·그래프의 관계, 축·범례·단위까지 표현됐다고 보지 않는다.
4. 그림 안 문자는 외부 발문과 분리한다. 문자층이 없는 그림은 원본 이미지를 필수 참조로 두고 `visual_only` 또는 `internal_text_unmapped`로 표시한다. OCR 결과는 원문 후보이지 검증 완료 텍스트가 아니다.
5. 그림 선택지는 선택지 번호와 개별 이미지 영역을 연결해야 한다. 축·단위·범례·곡선은 개별 검수하며, 기존 `null` 선택지를 임의의 설명문으로 채우지 않는다.
6. ㉠·ⓐ 같은 표식과 밑줄은 표식 문자, 밑줄 대상의 정확한 시작·끝, 원본 좌표를 별도로 저장한다. 표식이 있다는 사실만으로 밑줄 범위를 추정하지 않는다.
7. 중첩 자료는 다중 연결한다. 공통 지문 아래 추가 `<보기>`가 있으면 각 문항이 두 자료를 모두 가리키게 한다.
8. **그림을 이미지 한 덩어리로 저장하지 않는다.** 원본 크롭을 불변 증거로 두고, 의미 있는 영역을 `panel`, `embedded_text`, `speaker`, `figure_object`, `arrow`, `axis`, `legend`, `caption`, `option_visual` 등으로 분해한다. 각 요소는 원본 영역·문자 그대로의 내용·관계를 갖는다. 말풍선은 화자와 발화문을 연결하고, 도해의 화살표는 관찰된 방향과 과학적 해석을 분리한다.
9. 정규화 결과는 (가) 검색 가능한 원문 전사, (나) 기계가 다룰 수 있는 구조·관계, (다) 원본 이미지 참조의 세 층으로 묶는다. OCR/시각 모델은 후보만 만들며, 의미를 해석하지 못한 속성은 `null`과 검수 이슈를 남긴다. 이미지 자체가 정규화 데이터의 대체품이 되어서는 안 된다.
10. 완전성 점검은 단순히 문항 번호·선지 수를 세는 것이 아니라, **원본의 의미 있는 모든 영역이 데이터 요소나 명시적 미해결 영역에 대응하는지** 확인한다. 원본에 보이는 말풍선 3개가 데이터에 0개면 그 문항은 미완료다.

## 재정규화 순서와 통과 기준

1. **후보 생성:** 현재 2027학년도 9월 비언어 360문항을 재추출했고 선분 격자 후보 42개를 찾았다. `scripts/audit-sept-visual-structure.py`는 원본을 본 대표 3사례의 회귀를 막는다.
2. **시각 영역 분류:** 표 후보 42개를 원본과 대조해 진짜 표/그래프 격자/장식으로 분류한다. 표에는 셀·병합·행열 헤더, 그래프에는 축·단위·범례·계열·값, 흐름도에는 노드·화살표를 각각 확인한다.
3. **의미 입력:** 그림 내부 문자, 수식, 밑줄 대상, 이미지 선택지를 사람이 이미지와 대조해 입력한다. 모호하면 `null`과 이슈를 유지한다.
4. **검수·승격:** 문항 전체 크롭과 구조를 재투영해 누락·순서·대응 관계를 확인하고, 별도의 검수자가 원본과 독립 대조한 뒤에만 DB의 인증 상태를 올린다. 자동 번호·셀 수 검사는 인증의 대체물이 아니다.

이번 실행은 후보 JSON을 갱신했으며 공개 사이트나 DB의 검증 상태는 바꾸지 않았다.
