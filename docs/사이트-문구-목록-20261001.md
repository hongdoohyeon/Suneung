# 사이트 상시 문구 목록과 다듬기 제안 (2026-10-01)

범위: 매 페이지에 늘 나오는 문구, 안내·상태·오류·버튼·메타 문구. 소개·개인정보처리방침·이용약관·방법론·블로그 본문 같은 긴 글은 제외했다.
표기: **현재** 문구 → **제안**. 제안은 아직 사이트에 적용하지 않았다(승인 후 일괄 반영).

## 먼저, 전체 톤 정리

- 지금은 화면 문구가 **해요체**(…했어요, …보실 수 있어요)와 **합니다체**(…없습니다, …확인하세요)로 섞여 있다. 같은 화면 안에서도 섞인다(예: 상세 페이지 "시험지를 먼저 풀어보세요" + 아래 "자료를 찾을 수 없습니다").
- 제안 규칙: **화면 UI 문구(버튼·안내·오류·빈 화면)는 해요체**, **정책·소개·블로그·메타 설명은 합니다체**.
- 개발 용어("id", "데이터 로드", "split 형식 오류")가 사용자에게 보이는 곳은 일상어로 바꾼다.
- 이모지(⚠️)와 ·, —, → 같은 기호를 문장 장식으로 쓰는 곳은 줄인다(블로그와 같은 기준).

| 달력 | 이번 달 일정 없음. / 예정된 일정 없음. / 캘린더 로드 실패: | 이번 달에는 등록된 일정이 없어요. / 예정된 일정이 없어요. / 일정을 불러오지 못했어요. |

## 6. 검색엔진·공유 미리보기(제목과 설명 템플릿)

사용자가 직접 읽는 문구는 아니지만 검색 결과와 카카오톡 미리보기에 노출된다.

| 위치 | 현재 | 제안 |
|---|---|---|
| 시험 상세 제목 | {시험} {과목} 문제지·정답·해설 — 기출해체분석기 | 그대로(검색 의도와 일치) |
| 시험 상세 설명 | {시험} 기출 문제지·정답·해설 자료를 한 곳에서 확인하고 무료로 내려받으세요. | {시험}의 문제지와 정답, 해설을 한곳에서 내려받을 수 있어요. 공개된 등급컷이 있으면 함께 정리했어요. |
| 회차 설명 | …한 곳에서 확인하고 무료로 내려받으세요. | …모든 영역의 문제지·정답·해설을 한 페이지에서 확인하세요. |
| 홈 설명 | 문제지·정답·등급컷·해설지·영어 듣기 MP3·듣기 대본을 학년도·영역·시기로 해체하고 빠르게 찾아보세요. 수능·평가원·교육청·사관·경찰대·LEET·MEET. | 수능·모의평가·학평·사관학교·경찰대·LEET·MEET 기출을 학년도와 과목별로 찾아보세요. 문제지, 정답, 해설, 등급컷, 영어 듣기까지 한곳에서 볼 수 있어요. |
| 사이트 태그라인 | 학년도·영역·시기로 해체된 기출 자료실 | 학년도·과목별로 정리한 기출 자료실 |

참고: 「해체」는 사이트 이름(기출해체분석기)에서 오는 말인데, 설명 문장에서는 처음 보는 사람이 뜻을 바로 알기 어렵다. 이름은 그대로 두고 설명은 「정리한」으로 풀어 쓰는 것을 제안한다.

## 7. 한 번에 바꿀 때 영향받는 파일

- 정적 HTML 템플릿: `archive.html`, `exam.html`, `exam-set.html`, `404.html`, `calendar.html`
- 스크립트: `app.js`, `exam.js`, `state.js`, `lib/*.js`(report·share·download·exam-pdf·exam-viewer·exam-gradedist·calendar-page·dday)
- 빌드 템플릿: `scripts/build-data.py`(상세·회차 SSG 문장, 메타 설명), `scripts/render-site.py`(홈·허브·회차 목록)
- 같은 문구가 여러 곳에 중복돼 있어(예: 스포일러 안내, 헤더·푸터 마크업) 반영 때 한 곳씩 누락되지 않도록 검색으로 확인해야 한다.
