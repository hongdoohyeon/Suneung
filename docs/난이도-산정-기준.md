# 난이도 산정 기준

공개 설명(그래프 포함): `methodology.html` (render-site.py 의 `render_methodology` 가 실제 데이터로 생성). 계산: `scripts/build-data.py` 의 `compute_exam_scores`.
연구·검증 원본: 2026-09-29 (로컬 `tmp/difficulty-proto/`, gitignore) — 아래 수치는 그 결과이며 methodology.html 의 검증 표는 빌드 때마다 다시 계산된다.

## 추정기 (구간 자료 모멘트)
등급 경계 8개 + 비율 9개 → 구간 중점 × 비율로 평균·σ·왜도. 구간 안은 균등, 구간 분산 w²/12 보정. 정규 가정 없음.
- 상대평가: 비율 = `GRADE_RATIOS` (4·7·12·17·20·17·12·7·4%), 경계 = 등급컷. 경계는 정수 점수의 연속 근사(±0.5).
  - 원점수: 위 끝=만점, 아래 끝=`max(0, cut8 − (만점 − cut1))` → 평균 점수율 `mean`, `sd`.
  - 표준점수: 위 끝=`highestStandardScore`(없으면 cut1+(cut1−cut2)), 아래 끝=대칭 → 왜도 `skew`.
- 절대평가(영어): 경계 = `ABS_EDGES`(90·80·…·20), 비율 = 평가원 채점결과(data/english-grade-ratios.json). 한국사·학평 영어는 비율 자료가 없어 등급 없음.
- 순서가 어긋나거나 범위를 벗어난 컷은 계산에서 제외(`_full8`).

## 등급(1 매우 쉬움 … 5 매우 어려움)
묶음 = `tier_series_key` (시험군·교육과정·과목·선택과목·학년). 회차별로 쓸 수 있는 첫 지표(묶음 안에서 표본 ≥5, 서로 다른 값 ≥3):
`mean` → `skewtop`(왜도·표점최고점 z 합) → `skew` → `top` → `raw`. 영어(절대평가)는 `mean` 만.
값(높을수록 쉬움)의 중간순위 백분위: 회차 ≥10 이면 20/40/60/80% 5단계, <10 이면 3단계(쉬움 2·보통 3·어려움 4). `tierN`·`tierBasis` 를 저장해 화면에 병기.

## 검증 요약 (2026-09-29)
- 실측 분포(2026학년도 수능·9모, 38영역): 평균 오차 평균 0.045σ·최대 0.07σ(약간 낮게 나오는 편향), σ비 0.99~1.05, 왜도 상관 0.992.
- 절대평가 시뮬레이션(실제 분포 모양 50개 × 평균·σ 격자 2,000건): 평균 오차 0.76점, σ비 0.99. 천장 근처(평균 85)에서 −1.6점.
- 지표별 묶음 내 Spearman(평균 점수율 대비, 131묶음): 1등급 원점수컷 0.72 · 왜도 0.82 · 표점최고점 0.87 · 왜도+표점최고점 0.91.
- 기존 라벨 대비: 일치 57%, ±1단계 94%, ±3 이상 0.6%(대부분 학평·소표본).

## 한계
집단 실력과 시험 난이도 분리 불가(상대평가 구조), 선택과목별 표점은 집단 기준, 영어 실측 평균 미확보(시뮬만), 원점수 컷 일부는 학원 추정값, 새 회차 추가 시 기존 등급 변동 가능.
