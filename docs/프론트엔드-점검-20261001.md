# 프론트엔드 점검 (2026-10-01) — 모바일·태블릿·데스크탑

방법: 라이브(kicegg.com)를 브라우저에서 세 가지 크기로 열어 주요 페이지를 직접 보고, 가로 넘침·터치 크기·글자 크기·입력창·다크 모드를 스크립트로 측정했다.
크기: 모바일 375×812, 태블릿 세로 768×1024, 태블릿 가로 1024×768, 데스크탑 1280×800.
대상: 홈(기출검색), 시험 상세, 회차 페이지, 블로그 글 3편, 달력, 전체 회차, 난이도 기준.

## 2. 발견한 문제와 처리

| # | 문제 | 크기 | 처리 |
|---|---|---|---|
| 1 | **블로그 막대·선 그래프가 모바일에서 오른쪽이 잘리고 가로로 밀어야 보임**(최소 너비 480px 때문) | 모바일 | **수정함** — 그래프를 480px 기준으로 다시 그리고 최소 너비 제한을 풀어 화면에 맞춤(`method__fig--chart`) |
| 2 | **블로그 표의 숫자가 줄바꿈**("20 22", "117 ,39 7") — 8열 표를 343px에 억지로 넣음 | 모바일 | **수정함** — 표 최소 너비 600px + 줄바꿈 금지, 표 안에서 가로 스크롤 |
| 3 | **표준점수 분포 그래프의 오른쪽 끝 눈금(151)이 잘림** | 전 크기 | **수정함** — 마지막 눈금은 오른쪽 정렬, 첫 눈금은 왼쪽 정렬 |

| 5 | 통계 카드 3개가 2열 격자에서 한 칸 비어 보임 | 태블릿 | **수정함** — 자동 열 개수(최소 180px), 모바일은 2열 유지 |
| 6 | 헤더 검색창 글자 크기가 14px라 iPad 에서 입력할 때 화면이 확대됨 | 태블릿 | **수정함** — 터치 기기에서는 16px |

## 3. 남은 권장 사항 (미적용)

- **터치 크기**: 결과 행의 「문제지·정답·해설」 버튼과 필터 알약이 36px, 헤더 아이콘이 40px로 권장 44px보다 작다. 눌러 보면 불편하진 않지만(간격이 넉넉함) 모바일에서만 40px 이상으로 키우는 것도 방법이다. 홈 「최근 시험」 카드의 제목 링크(20px 높이)는 카드 전체를 링크로 만들면 좋다.
- **태블릿 세로(768)**: 시험 상세가 모바일 레이아웃이라 정보 카드가 전체 폭으로 넓다. 두 칸으로 나누려면 `.exam__grid` 의 분기점을 900px 근처에서 760px 로 낮추면 되지만 시험지 미리보기 폭이 좁아져 득실이 있다.
- 블로그 선 그래프에서 값이 비슷한 해(2025년 국어 139·수학 140 등)에는 숫자 라벨이 겹친다. 라벨을 위아래로 어긋나게 하면 해결된다.
- 홈 첫 화면 속도(LCP 5초대)는 `docs/사이트-점검-20261001.md` 참고.
