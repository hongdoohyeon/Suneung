# 문항 원본 충실도 설계

문항 데이터는 검색용 텍스트와 원본의 시각적 의미를 분리해 보존한다. 자동 추출이
실패해도 원본 정보가 사라지지 않도록 모든 구조화 단위는 PDF 페이지, 좌표, 참조
이미지로 역추적할 수 있어야 한다.

## 표현 계층

1. 원본 PDF와 SHA-256을 불변 증거로 보존한다.
2. 페이지와 문항·지문·보기 단위의 무손실 PNG를 생성한다.
3. PDF 문자와 좌표를 `raw_text`로 보존한다.
4. 인쇄 줄바꿈만 제거한 내용을 `normalized_text`로 저장한다.
5. 문단, 목록, 표, 그림을 `content_blocks` 트리로 저장한다.
6. 밑줄과 기호는 `text_annotations`로 텍스트 범위와 원본 좌표에 연결한다.

이미지는 OCR 대체물이 아니라 원본 대조 기준이다. 검색과 접근성에는 구조화 데이터가
사용되고, 구조로 완전히 표현할 수 없는 자료에는 항상 참조 이미지가 함께 제공된다.

## 표현하기 어려운 요소

| 원본 요소 | 구조화 표현 | 필수 원본 보존 |
| --- | --- | --- |
| 밑줄 + ㉠, ⓐ | `underlined_span`, 표식, 대상 문자열, 문자 범위, 좌표 | 해당 지문 크롭 |
| 윗줄·아랫줄·강조 | `emphasis_span`과 표현 종류 | 해당 문장 크롭 |
| 문단 | `paragraph` 블록, 순서, 좌표 | 지문 크롭 |
| `<보기>`와 불릿 | `heading` + `bullet_list` + `bullet_item` | 보기 전체 크롭 |
| 표 | `table` → `row` → `cell`, 행·열 병합 정보 | 표 크롭 |
| 그래프 | 축·범례·단위·계열 메타데이터와 데이터 점 | 그래프 크롭 |
| 지도·삽화·사진 | `figure`, 캡션, 대체 설명, 내부 표식 좌표 | 원본 이미지 또는 크롭 |
| 수식 | LaTeX 또는 MathML, 읽기용 문자열 | 수식 크롭 |
| 두 자료의 대응선 | 요소별 식별자와 관계 edge | 자료 전체 크롭 |

텍스트 범위는 정규화문에 대한 `start_offset`과 `end_offset`으로 지정하되, 줄 결합으로
오프셋이 바뀌어도 복구할 수 있도록 원본 좌표를 같이 저장한다. 표식이 밑줄 앞에
독립적으로 인쇄된 경우 표식 문자와 밑줄 대상 문자열을 분리한다.

## 자동 추출과 검수

- PDF의 word/span 좌표와 vector drawing을 함께 읽는다. 밑줄은 글자 아래의 수평선과
  인접 텍스트를 결합해 후보를 만든다.
- PDF 줄 끝에 공백이 있으면 단어 경계로, 없으면 인쇄 중 분리된 단어 후보로 취급한다.
- 첫 줄 들여쓰기, 세로 간격, 글꼴 변화, 불릿 기호, 테두리로 블록 경계를 판정한다.
- 표는 선분 교차점과 셀 내부 문자 좌표로 복원하며, 병합 셀과 헤더를 별도 기록한다.
- 그래프와 그림은 텍스트 객체와 벡터 객체를 구조화하되, 의미를 확정하지 못하면
  이미지 자산을 정답 표현으로 유지하고 검토 큐에 넣는다.

자동화가 확정할 수 없는 경우 값을 추정하지 않는다. `LINE_JOIN_AMBIGUOUS`,
`ANNOTATION_TARGET_AMBIGUOUS`, `TABLE_GRID_AMBIGUOUS`, `VISUAL_ONLY_CONTENT` 같은
이슈 코드로 검토 큐에 남긴다.

## 완료 조건

- 원본 문자·이미지 객체의 누락이 없다.
- 구조 블록을 원본 좌표에 다시 투영할 수 있다.
- 문단·불릿·표의 개수와 순서가 원본과 일치한다.
- 밑줄 표식과 대상 문자열의 연결이 원본과 일치한다.
- 문항과 공통 지문이 중복 저장되지 않고 관계로 연결된다.
- `raw_text_extracted`, `geometry_verified`, `structure_reviewed`,
  `normalized_text_verified`를 독립적으로 기록한다.

정규화문과 구조가 모두 검증되기 전에는 임베딩, RAG, JEV의 확정 데이터로 승격하지
않는다.
