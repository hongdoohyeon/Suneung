# 정시 모의지원 라인 산정 검증

`scripts/verify-lineup.mjs` 실행 결과 요약. 알고리즘 내부 일관성 점검과 한계 정리.

## 산식

```
score = (국어 백분위 × ratios.국어
       + 수학 백분위 × ratios.수학
       + 탐구 백분위 × ratios.탐구) / Σ ratios

diff = score − 학과 70%컷
line ≥ +1.5 → 안정
     ≥  0   → 적정
     ≥ −1.5 → 소신
     <  −1.5 → 지원 어려움
```

영어·한국사는 학교마다 환산 단위가 천차만별(서울대 -2.0 / 고려대 200점 / 연세대 100점)이라
0~100 백분위로 정규화하면 영어 1등급=100이 영역 백분위(95)보다 높아 systematic bias가 생김.
실제 사용자=컷 시뮬레이션에서 **평균 +1.26 위로 score가 밀리는** 문제 발견 → 가중평균에서 제외하고
UI 힌트로만 표시하도록 수정.

## 검증 결과

### 1. 임계값 정합성

사용자 백분위 = 학과 70%컷 시 환산값 차이:

| 지표 | 값 |
|---|---|
| 표본 수 | 205건 |
| 평균 diff | +0.000 |
| median   | +0.000 |
| 10~90% 범위 | 0.00 ~ 0.00 |

→ "사용자=컷 → 적정 경계" 가정이 알고리즘 내부에서 정확히 성립.

|  88 |  17 |  13 |  14 | 161 |

→ 백분위 단조 증가에 따라 안정 비율도 단조 증가, 분포 합리적.

### 4. 인문/자연 트랙 비대칭 (수학 약점: 국 95 / 수 90 / 탐 92)

같은 학교 안에서 인문 / 자연 트랙 score 차이:

| 학교 | 인문 | 자연 | 인문 우위 |
|---|---:|---:|---:|
| 연세대 | 92.71 | 92.00 | +0.71 |
| 한양대 | 92.50 | 92.06 | +0.44 |
| 성균관대 | 92.67 | 91.78 | +0.89 |
| 시립대 | 92.50 | 91.88 | +0.63 |

→ 수학 약점 사용자는 인문 트랙이 약 0~0.9 유리, 현실 반영.

## 한계

### A. 외부 합격 데이터로 절대 정확도 검증 불가

- **어디가(adiga.kr)** — 동적 SPA + 회원 로그인 필요한 페이지 다수, 자동 수집 어려움
- **종로학원·메가스터디 PDF** — 매년 발간이지만 binary, 본문 추출 실패
- **개별 학생 점수+합격 결과 매핑** — 개인정보 보호로 자발적 동의 없이 수집 불가
- 현재 검증은 알고리즘 **내부 일관성**만 보장 (사용자=컷 → score=컷)

### B. 2025학년도 발표 방식 변화 (종로학원 분석 기준)

> 2024학년도까지는 대부분 대학이 국·수·탐 3개 영역 합산 평균 백분위(70%컷)를 공통 기준으로 제공.
> 2025학년도 정시 결과 발표에서는 99개 대학 중
> - 9개 대학: 자체 산출 환산점수만 공개
> - 72개 대학: 국·수·탐 과목별 백분위를 **각각 다른 학생의 컷 점수**로 공개

→ `manual-results.json` 의 `pct70` 이 일부 학교에서 한 학생의 평균이 아닐 수 있음.
   라인 산정은 이 가정을 디폴트로 두고 있어 학교별로 +-1~2 정도 오차 가능.

### C. 영어·한국사 가/감점 미반영

- ratios 가중평균에서 영어·한국사 제외 → 영어 6등급, 한국사 5등급 같은 사용자에겐 실제보다 후한 결과
- 학교별 영어 환산이 절대평가라 score 단위와 충돌 → 가/감점 직접 적용 불가
- UI 힌트 "영어 별도 가/감점" 으로 사용자 주의 환기

### D. 트랙 매칭 휴리스틱

- 학과명 키워드(인문/자연/의약)로 트랙 매칭 — 학교마다 트랙 라벨이 다양해 일부 학과는 잘못 매칭될 수 있음
- 예: 고려대 의과대학이 인문 트랙으로 잡히는 케이스 (자연 트랙 키워드 미스매치)

## 권장 사용

- **참고용 도구**로만 사용 — 실제 지원 전 입학처 공식 환산표 + 어디가 발표 자료 병행 확인
- 영어 1~2등급, 한국사 1~3등급 사용자에겐 score 정확도 ±1 안팎으로 양호
- 영어 5등급 이하, 한국사 6등급 이하면 실제 환산점수가 score 보다 낮을 가능성 큼

## 재검증

```bash
node scripts/verify-lineup.mjs
```

알고리즘이나 입력 데이터를 변경했을 때 `평균 diff` 가 0에서 멀어지면 단위 충돌이 생긴 것.
