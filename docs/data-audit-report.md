## 정답 배열 품질

`data/answers.json`은 공식 답지에서 자동 추출한 보조 데이터이며 현재 학생 화면의
다운로드·등급컷 기능에는 사용하지 않는다.

- 공식 답지 625건 재추출 후 위치 보존 표 파서를 추가했다.
- 검증 완료 배열 1,407건만 `data/answers.json`에 유지한다.
- `?` 또는 문항 수 불일치 133건은 `data/answers-unverified.json`으로 격리했다.
- 격리 데이터에는 원본 배열, 시험 메타, 답지 URL, 실패 사유가 보존된다.
- 검증 파일의 `?`, 표준 문항 수 불일치는 CI 오류로 처리한다.

따라서 자동 보정으로 정답을 잘라내거나 `?`를 채우지 않으며, 미확정 정답이 다시
학생 기능에 들어오는 것을 차단한다.

## 예비·예시 문항 판단

과거 보고서의 “2022 예시문항 영어·한국사·사탐·과탐 전부 누락” 주장은 근거가
부족해 폐기했다. 평가원 출처 공식 안내는 공통+선택 구조 도입 영역을 국어·수학·
직업탐구로 명시한다. 현재 자료 범위를 결측으로 확대하려면 당시 첨부 원문에 해당
영역별 예시문항이 실제 수록되었는지 먼저 확인해야 한다.

- 공식 발표 안내: <https://www.ebsi.co.kr/ebs/ent/enta/retrieveMoeAnncDatView.ebs?datNo=127360>

## 재현 명령

```bash
npm run validate
python3 scripts/regen-exam-splits.py --check
python3 scripts/validate-sitemap.py
python3 scripts/coverage-report.py
node scripts/audit-answers.mjs
```

URL 전수 GET은 배포본을 대상으로 별도 실행한다. HEAD만 지원하지 않는 저장소가
있으므로 실제 무결성 판정에는 GET을 사용한다.
