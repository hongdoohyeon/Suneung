## 2. 공식 교체

- 평가원 게시판(수능 기출·모의평가) 첨부 5,686개(약 6.4GB)를 받아 풀었다. 파일명을 정규화(I/1→Ⅰ, 물리학→물리 등)해 시험·영역·문서 종류가 정확히 하나만 맞는 파일을 짝으로 인정했다(짝 629개).
- 미러 PDF와 글자(5글자 조각 일치율)·쪽수·축소 이미지로 대조했다. 문제지는 206건이 글자까지 일치, 나머지는 쪽수가 같거나 공식 쪽이 정본이라 교체했다.
- **정답 링크 267건 중 209건은 사설 '정답&해설' 합본(5~11쪽)이던 것을 공식 1쪽 정답표로 바꿨다.** 이 중 21개 시험은 다른 해설 링크(EBSi)가 없어 해설이 사라졌다(2012~2016학년도 모의평가 등). 필요하면 별도 해설 출처를 찾아야 한다. 합본 문서라 `answerIncludesSolution` 표기는 제거했다.
- 제2외국어·사탐·과탐 정답이 한 파일에 합쳐진 공식 정답표(2017 6월 등)는 과목마다 같은 합본을 연결했다(8건).
- 비어 있거나 열리지 않던 미러 3건(1999·2000 영어 문제지, 2012 6월 공업입문)은 공식 원본으로 수동 교체했다.
- 교체한 문제지 238건의 흐린 표지 이미지(`previews/`)도 새로 만들었다. 검증기(`validate-exams.mjs`)의 "구형 수능은 legacy-csat-v2 자산" 규칙은 공식 교체분을 허용하도록 고쳤다.

## 3. HWP→PDF 변환본 185개 검사

- 전수 점검: 모두 열리고 쪽·글자 정상, 한글 비율·학년도도 정상. 빈 쪽은 20개(대부분 HWP 말미의 빈 쪽).
- 원본 HWP 텍스트와 대조(원본이 남은 87건): 본문이 충분한 파일은 94~100% 일치. 낮은 값은 표·글상자를 읽지 못하는 대조 도구의 한계(LEET 정답표, 논술 등)로 결함이 아니다. HWP 3.0 원본 6건은 도구가 못 읽어 눈으로 확인했고 정상.
- 눈으로 본 결과 **수식이 깨진 변환본 4개**를 확인했다(교체 불가, 목록만):
  - id 4675 경찰대 2006 수학 문제지: `PMATRIX`·`ANGLE`·`¿` 등 수식 스크립트가 글자로 샌다. 머리말 칸도 겹침.
  - id 4608(2007 과학탐구 생명과학Ⅱ), id 7020(2008 과학탐구 물리Ⅱ) 정답·해설: `rmNa+¿−K+¿¿`, `E1=−13.6¿¿(eV)`. → **공식 정답표 PDF(평가원 게시판)로 교체 완료.** 두 시험 모두 EBSi 해설(solutionUrl)은 그대로 있다.
  - id 2114 LEET 추리논증 2020: `BIGCIRC` 등 소량.
  - 다시 변환하려면 한컴오피스(Mac에 설치됨)로 수동 변환해야 한다. LibreOffice 7.6 은 HWP 5.x 를 읽지 못한다.

## 5. 한계와 남은 일

- 1994~2002학년도 평가원 옛 수능 자료는 파일명이 코드(`C20003.pdf` 등)라 자동 짝짓기를 하지 못했다. 개별 확인이 필요하다.
- 2005~2013학년도 모의평가 중 공식이 HWP뿐인 127개 파일은 PDF 교체를 하지 않았다(사이트는 HWP 변환을 쓰지 않는 방침).
- 학평 2000년대 251개는 공식 출처를 찾지 못했다(서울시교육청 2022년 이전 게시글 비공개, EBSi는 2006학년도부터).
- "공식 여부"는 평가원 게시판 직접 수집 여부로 판단했다. EBSi 경유 7,202개와 `kice`·`edu`·`essay`·`ged` 자체 보관 15,368개는 이번 범위가 아니다(출처 라벨이 없어 구분 불가).
